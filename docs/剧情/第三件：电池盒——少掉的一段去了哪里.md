# 第三件：电池盒——少掉的一段去了哪里

> 原创器材示意物件。盒上的痕迹与随附记录属于故事设定。

## 剧情流程

行军图上写着“器材先交”。带着寻找实际交接记录的问题，玩家打开电池盒，首先注意到的却是盒体外侧两处不一样的带子：**固定带接头**叠着新旧两段材料，旁边的**备用背带**则留下一截较齐整的边缘。

玩家转到背面，放大这两处痕迹。固定带常受摩擦的位置有散开的纤维，备用背带的末端却更整齐，像是曾被裁下一段。视线从**背带裁口**移到接头，一个解释似乎很自然：备用背带是不是都拿来修补这个盒子了？

这个猜想还需要记录来回答。查看盒内时，玩家发现一张折起的纸，露出的栏题是**“器材交接”**。展开后，上半部写着：

> 器材交接  
> 前批器材，已交。  
> 余带补接固定带，续用。

**“前批器材，已交”**回应了地图上的“器材先交”。前面看到的是安排，现在找到了交接记录。继续往下读，**“余带”**两个字又让玩家停下来：纸上说的是剩下的带子接补后继续使用，那么此前裁下的那一段去了哪里？

玩家回看固定带，纸上的“补接固定带”与眼前的接头对应起来。但这个接头只能解释余带的用途，不能解释所有材料的去向。顺着纸面继续向下，另一组有独立栏题的记录出现了：

> 修补用料·领出联（器材交接后）  
> 任务：转三  
> 材料：备用背带  
> 数量：一段  
> 领用联随修补物存。

这是**修补用料领出联**。**“任务：转三”**与名单上的第三项编号相同，材料栏写着备用背带，数量是一段。它把裁口、固定带接头和两个不同去向连在了一起：一段背带在器材交接后被领作“转三”的修补用料，余下的带子则用于补接固定带，让器材继续搬运。

最初“全部用来修盒子”的猜想至此被修正。眼前的器材既留下了自己继续使用的接补，也保存着向另一项任务领出材料的记录。

“转三”让玩家重新想到那两名后随人员。既然器材已经交接，而材料又领给了他们所在的任务，是不是两个人也已经到了？玩家重新核对上下两组栏题：**器材交接记录**确认的是前批器材；**领出联**记的是修补用料。两处都没有人员接收的文字。

于是，调查继续落在材料上。它究竟修补了什么？领出联没有写具体物品，却在最后一行留下了寻找方向：**“领用联随修补物存”**。用途记录应当和被修补的物件放在一起。接下来要找的，是一件保留着旧补料和领用小票的东西。

玩家保存本件查明的两项结果：前批器材已有交接记录；一段备用背带为“转三”领出作修补用料，余带补接固定带后继续使用。前批的结果已经找到，后批的经过则通过这段材料留下了新的线索。

离开电池盒时，问题变得具体：

> 一段备用背带领去修补了。哪件物品保留着它的领用记录？

## 玩法

物件调查通过旋转、放大、翻看盒内折纸和并排对照完成。先比较**磨损边缘、背带裁口和固定带接头**，再展开纸张，分别读取上半部的交接记录和下半部的领出联。两组文字保持各自的栏题，玩家可以来回查看。本件没有接线、组网或发送练习，读到记录即可继续。

建档时可保留两项判断：

- 前批器材已有交接记录。
- 一段备用背带在器材交接后，为“转三”领出作修补用料；余带补接固定带后继续使用。

同时保留两个轻度干扰项，引导玩家区分不同材料去向和记录对象：

| 容易误判的选项 | 核对依据 |
| --- | --- |
| 备用背带全部用于接补本盒固定带。 | “余带补接”只说明剩余材料的用途，领出联还记着另行领出的一段。 |
| 前批器材已交，说明“转三”也已完成接收。 | “已交”写在器材交接栏下；“转三”出现在修补用料栏，两处记录的对象不同。 |

选择后可以回看纸张与痕迹，修改判断，保留已有发现。

## 提示

提示先指出值得比较的位置，再提醒记录中的关键字。玩家主动查看，自己完成判断。

| 卡住的位置 | 第一次提示 | 再次提示 |
| --- | --- | --- |
| 只看到带子破旧 | 比较固定带常受摩擦的位置与备用背带的末端。 | 看看散开的纤维和齐整边缘，再找纸上有没有材料用途记录。 |
| 认为备用背带全用来修盒子 | 回看“补接固定带”前面的两个字。 | “余带”说明的是哪一部分？再读下方领出联的数量栏。 |
| 不知道两组记录是否都在说交接 | 分别看看上半部和下半部的栏题。 | “已交”的对象是什么？“转三”下面登记的又是什么？ |
| 找不到下一步方向 | 领出联的最后一行说明了另一联放在哪里。 | 哪件物品既有修补痕迹，又可能保留领用小票？ |

## 线索与道具文字

### 盒体痕迹

| 位置 | 可见内容 |
| --- | --- |
| 固定带常受摩擦的位置 | 磨损边缘与散开的纤维 |
| 固定带接头 | 新旧两段材料相叠的接补 |
| 备用背带末端 | 较齐整的裁口 |

痕迹引出材料去向的问题；是否领出、领给哪项任务以及数量，由纸面记录说明。材质与形状相似只用于辅助观察。

### 盒内记录

上半部：

> 器材交接  
> 前批器材，已交。  
> 余带补接固定带，续用。

下半部：

> 修补用料·领出联（器材交接后）  
> 任务：转三  
> 材料：备用背带  
> 数量：一段  
> 领用联随修补物存。

两部分在同一张纸上各占一块区域。下半部的任务、材料与数量逐行列出，便于之后与领用联逐项核对。

### 线索怎样得出结论

| 线索 | 如何发现与核对 | 得到的理解 |
| --- | --- | --- |
| **背带裁口与固定带接头** | 翻看盒体，比较两处边缘和接补位置 | 材料可能经过裁取与接补，需要查找用途记录 |
| **器材交接记录** | 展开盒内纸张，先读栏题再读“前批器材，已交” | 前批器材已有交接记录，回应地图上的先交安排 |
| **“余带”与领出数量** | 将“余带补接”与下半部“数量：一段”对照 | 材料分作两个去向：一段领出，余带续用 |
| **任务、材料、数量三栏** | 读出“转三—备用背带—一段” | 后续可以用这三项寻找对应的领用记录 |
| **领用联存放说明** | 读领出联末行“领用联随修补物存” | 下一步查看有旧补料及领用小票的物件 |

## 后续照应与自由调查

草鞋的小票写着同样的**任务编号、材料与数量**，并补上“用途：补履二只”。玩家找到它后，才能把领出记录与具体用途联系起来。旧补料的形状和纹路提供辅助，三栏记录与用途文字承担核对依据。

如果先调查电池盒，本件的栏题足以说明器材交接和材料领出；之后读到名单，再将“转三”与“后随二人”对应。若草鞋已先建档，玩家可以直接并排核对两联，继续追查后随二人的接收结果；若回执也已读到，则用这份领出记录补齐任务经过。
