# 第四件：草鞋——旧补料的来处

> 原创数字叙事物件。草鞋上的痕迹、领用小票与照应安排属于故事设定。

## 剧情流程

电池盒留下了一条明确的方向：**领用联随修补物存**。带着这句话，玩家查看两只并排放着的草鞋。一大一小的鞋形首先映入眼帘，翻到鞋底后，一处与草编不同的**带状旧补料**更值得注意。

玩家放大旧补料，沿着它的边缘查看。补料压住了原先断开的编结，两端固定在较完整的位置，像是把断处重新连了起来。它的形状让人想起盒上裁过的背带，但要确认材料来处，还需要那张领用记录。

鞋侧露着一张折起的小票，纸边能读到**“领用联”**。玩家展开它，先看见熟悉的三栏：

> 修补用料·领用联  
> 任务：转三  
> 材料：备用背带  
> 数量：一段  
> 用途：补履二只。

把它与盒内的**领出联**并排查看，**任务编号、材料名称、数量**逐项对应：都是“转三”，都是备用背带，都是一段。最后一栏则给出了电池盒里没有的答案——**“补履二只”**，也就是修补两只鞋。

那段从器材备用物料中领走的背带，终于有了具体去向。玩家回看鞋底，旧补料跨过断口的位置与修补用途呼应。盒内留下领出记录，修补物旁保存领用记录，两张小票分别记录了材料从哪里领出、用在什么地方。

但眼前这两只鞋，一只大、一只小。它们会不会正好属于名单上的两名后随人员？玩家再读小票，“二只”写在**用途栏**里，数的是修补的鞋。鞋形给了一个联想，记录尚未写出谁穿哪一只。

小票背面还露出一截字迹。玩家翻过来，读到**照应记录**：

> 留一组照应，候后随二人同行。

**“后随二人”**将这一行与名单、行军图中的任务对象接了起来。此前看到的是器材先交、材料领出，如今后批的安排有了更具体的内容：有人被安排留下照应，等待两名后随人员一起继续走。

“留一组”说明这项任务不仅分到了修补用料，也安排了照应人员。玩家把它与图上的前后批记录对照，器材先交与留组候同行便成为同一安排的两个部分。

读到这里，似乎已经能想见他们穿着补好的鞋继续行进。但纸上的字是**“候”**，不是“已接”。它记下了等待同行的安排，还没有告诉玩家这次接应最后怎样。

玩家留下本件的两项发现：小票记着一段备用背带用于补履二只；背面留有一组照应后随二人、候其同行的安排。材料去向得到了解答，任务的经过也多了一环，而名单最初留下的接收问题仍等着另一份记录回答。

离开草鞋时，调查重新回到那两个人：

> 有了补履和同行的安排，后随二人后来被接收了吗？

## 玩法

玩家先翻看鞋底、放大旧补料，再展开鞋侧小票，最后翻到背面读取照应安排。小票的位置与露出的“领用联”提供可见入口。本件不设修补或行走练习，调查由补料、领用联与两联对照完成。

若电池盒已经建档，可并排查看两联，按**任务、材料、数量**逐项核对，再读草鞋一侧新增的**用途栏**。若先看草鞋，则先保存本件记录，之后再找对应的领出联。

建档时可保留两项判断：

- 领用联记着一段备用背带用于“转三”的补履二只。
- 小票背面记着留一组照应，候后随二人同行。

同时提供两个轻度干扰项，引导玩家区分物件数量、人员身份与任务结果：

| 容易误判的选项 | 核对依据 |
| --- | --- |
| 两只鞋大小不同，因此能确定它们分别属于两名后随人员。 | 小票的“二只”统计修补的鞋，没有登记谁穿哪一只。 |
| “候后随二人同行”说明后随二人已经到达接应处。 | “候”记着等待同行的安排，纸上尚无人员接收文字。 |

选择后可以返回观察、修改判断，已经发现的线索保留。

## 提示

提示由玩家主动查看，先指向观察位置，再提示需要核对的记录。

| 卡住的位置 | 第一次提示 | 再次提示 |
| --- | --- | --- |
| 只注意到两只鞋的大小 | 翻到鞋底，看看草编之外还有什么材料。 | 沿那段补料的边缘，看它压住了哪处断口。 |
| 仅凭纹路就认定来自电池盒 | 鞋侧的小票露出了什么栏题？ | 展开领用联，与已找到的领出联逐项核对任务、材料和数量。 |
| 读完用途便准备离开 | 小票背面还有字迹。 | 翻面看看，除了材料用途，还留下了什么安排？ |
| 把鞋的数量当成人员身份 | “二只”写在哪一栏？ | 用途栏数的是修补的鞋，哪里记着各自的穿用者？ |
| 把同行安排当成到达结果 | 留意“后随二人”前面的那个字。 | “候”说明正在等待，接收完成还需要怎样的记录？ |

如果尚未发现盒内领出联，材料来源的提示只引导读本件小票，保留日后对照的方向。

## 线索与道具文字

### 草鞋与旧补料

| 位置 | 可见内容 |
| --- | --- |
| 两只鞋的整体 | 大小不同，均有使用痕迹 |
| 鞋底旧补处 | 带状补料跨过断开的编结，两端固定在较完整的位置 |
| 鞋侧 | 折起的小票，纸边露出“领用联” |
| 小票背面 | 翻面可读的照应安排 |

旧补料让玩家找到值得核对的物件，大小和纹路提供观察细节。材料的任务归属、数量与用途由小票承担。

### 领用小票

正面：

> 修补用料·领用联  
> 任务：转三  
> 材料：备用背带  
> 数量：一段  
> 用途：补履二只。

背面：

> 留一组照应，候后随二人同行。

任务、材料、数量三栏与盒内领出联采用对应的顺序。“用途”是本件新给出的内容，照应安排在同一张小票背面。

### 线索怎样得出结论

| 线索 | 如何发现与核对 | 得到的理解 |
| --- | --- | --- |
| **带状旧补料** | 翻看鞋底，观察补料如何跨过断口 | 找到实际修补痕迹，继续查小票上的材料记录 |
| **领用联三栏** | 展开小票，按任务、材料、数量与盒内记录对照 | “转三—备用背带—一段”的领出与领用相互对应 |
| **“补履二只”** | 从三栏继续读到用途栏 | 电池盒领出的修补用料有了明确用途 |
| **“留一组照应”** | 翻到小票背面 | 后批安排包含留组照应 |
| **“候后随二人同行”** | 与名单事项、地图后批记录核对，留意“候”字 | 等待同行的对象是后随二人，接收结果仍待查 |

## 后续照应与自由调查

草鞋回应电池盒留下的材料去向问题，也补充行军图的后批安排。到这里，玩家已经可以把任务内容、接应改点、前批交接、材料领用和候同行安排联系起来。

名单上的**“回执另存”**与**裁口**仍未找到对应记录。它们是接下来查明最终接收结果的依据；草鞋不提前写出“已接”，也不直接指定借用物的名称。

前面的剧情按名单、行军图、电池盒、草鞋的调查顺序叙述。若先看草鞋，本件的小票已经能说明用途和照应对象；其他物件建档后再核对两联与分批安排。若已先读过饭碗回执，则用草鞋补齐材料用途与候同行的经过，回看它们和同项接收记录的关联。
