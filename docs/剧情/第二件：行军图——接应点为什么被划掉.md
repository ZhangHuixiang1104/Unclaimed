# 第二件：行军图——接应点为什么被划掉

> 原创数字叙事物件。接应小示意中的任务、记号与文字属于故事设定。

## 剧情流程

名单留下了寻找接收记录的问题。打开行军图，一张夹在背面的折纸露出纸边，上面又出现了**“转三”**。这个编号把注意力从行军路线引向了小纸：它会不会记着后随二人的去向？

编号旁边是一个**被打叉的圈点**。一条线从圈点附近伸出，到折边处便看不见了。玩家放大纸边，叉线清楚地划过原来的位置。这个点为什么被划掉？难道接应取消了？

玩家翻到背面，展开小纸，原来断在折边处的线条接了起来。它是一支**改点箭头**，从被打叉的圈点旁引出，指向另一处没有打叉的圈点。纸张上方写着“接应安排”，下方附有**图例**：

> 圈点：接应处  
> 打叉：旧点停用  
> 箭头：改定接应处

沿着箭头看过去，旧点与新点连在了一起。旧点虽然停用了，纸上却还有一个改定的接应处。玩家继续寻找文字，想知道为什么要换地方。

旧点旁的一条短引线连着**旧点旁注**：

> 无遮蔽，不宜久候。

箭头另一端，**新点旁注**写着：

> 改在背风处接应。

两句话说明了改点的原因和去向。原来的位置缺少遮蔽，不适合让人一直等在那里，所以接应改到了背风处。“接应取消”的猜想也在此被排除：新点旁仍然明确写着“接应”，最初那道叉线只是这次变更的一部分。

新点旁还有一条短引线，通向纸张下方的**分批记录**。玩家顺着它往下读，发现两行文字外侧画着同一个**共同括线**，上方注明：

> 两批均往改后接应处。

括线中的第一行是“前批：器材先交”，第二行是“后批：转三，后随二人，改点接应”。两行各有批次，去向却由同一个括线说明：都前往改后的接应处。

玩家把这行**“转三—后随二人”**与名单对照。名单给出了第三项任务的内容，这张小示意则补上了它的接应安排：器材先交，后随二人按后批接应，目的地已经变更。

读到“器材先交”，似乎已经接近一个结果。但视线回到上方，**“转送安排”栏题**提醒玩家，这张纸写的是要怎样交接。纸上没有“已交”或“已接”，实际交接记录还没有找到。“先交”与“已交”只差一个字，却分别回答安排和结果。

玩家留下两项查明的判断：旧点因无遮蔽而停用，接应改到背风处；前后两批都按这个新位置安排，器材先交，后批接应“转三”的后随二人。

至此，名单上的任务多了地点和批次，却仍缺接收结果。返回工作台时，新的问题随之出现：

> 接应点改了，器材被安排先交。后续物件留下了什么实际交接记录？

## 玩法

调查主要通过放大、翻面、展开折纸和并排对照完成。玩家先从纸边发现编号与叉线，展开后追踪箭头，再沿短引线找到两处旁注与分批记录，最后核对判断。所有纸面内容均可直接查看。

正面的历史路线可用阶段按钮或时间滑块查看，附有出处与时间卡，作为可选背景阅读，不解锁线索也不参与建档。背面的原创接应小示意随时可翻看，接应安排由它自身的图例和文字解释。

玩家建档时可以保留以下两项判断：

- 旧接应点因无遮蔽而停用，改在背风处接应。
- 两批均往改后接应处，前批安排器材先交，后批安排接应“转三”的后随二人。

判断中还放入两个容易混淆的选项，让玩家回到纸面核对：

| 容易误判的选项 | 核对依据 |
| --- | --- |
| 旧点被划掉，说明这次接应已经取消。 | 箭头终点的旁注仍写着“接应”，取消的是旧点的使用。 |
| 仅凭这张图，已经可以确认前批器材交到了新点。 | “器材先交”位于“转送安排”栏下，实际交接结果需要另一份记录。 |

选择后可以继续观察、修改判断，已有线索保留，不扣分、不重置调查。

## 提示

提示由玩家主动查看。先提醒观察位置，再提示需要对照的文字，判断仍由玩家完成。

| 卡住的位置 | 第一次提示 | 再次提示 |
| --- | --- | --- |
| 只看被打叉的圈点 | 这条线在折边处断开了，展开后看看另一端。 | 对照图例，沿箭头找到终点，再读终点旁的文字。 |
| 不清楚改点原因 | 两个圈点各连着一条旁注。 | 旧点为什么“不宜久候”？新点注明了什么条件？ |
| 不清楚两批的去向 | 看看两行记录外侧的括线连着哪里。 | 读括线顶端，再分别核对“前批”和“后批”所在行。 |
| 把安排当成交接结果 | 先看这张表的栏题，再找接收文字。 | “器材先交”写在“转送安排”下，纸上是否另有“已交”或“已接”？ |

## 线索与道具文字

### 接应小示意

小纸标题为“接应安排”。旧点打叉，新点保留，两点之间由单向箭头相连。无箭头的短引线将旁注连接到各自的位置。

| 位置 | 文字 |
| --- | --- |
| 旧点旁注 | 无遮蔽，不宜久候 |
| 新点旁注 | 改在背风处接应 |
| 下方图例 | 圈点：接应处；打叉：旧点停用；箭头：改定接应处 |
| 分批记录外侧的括线顶端 | 两批均往改后接应处 |

### 分批记录

| 批次 | 转送安排 |
| --- | --- |
| 前批 | 器材先交 |
| 后批 | 转三，后随二人，改点接应 |

两行共用一条外侧括线，括线与新点通过短引线对应。“转三”和“后随二人”保持在同一横行，便于与名单核对。

### 线索怎样得出结论

| 线索 | 如何发现与核对 | 得到的理解 |
| --- | --- | --- |
| **纸边编号与打叉圈点** | 放大折纸边缘，认出“转三”并注意异常标记 | 找到与名单任务有关的另一份记录，产生改动原因的疑问 |
| **改点箭头与图例** | 展开纸张，沿箭头查看两端，再读图例 | 旧点停用，另有改定接应处 |
| **旧点与新点旁注** | 顺着各自的短引线，将文字与位置对应 | 旧点无遮蔽、不宜久候，因此改在背风处接应 |
| **共同括线与分批记录** | 从新点沿引线往下看，读括线顶端和两行安排 | 两批同去新点，器材先交，后批接应后随二人 |
| **转送安排栏题** | 将“器材先交”放回所属栏位阅读 | 本件记着安排，尚未给出实际交接结果 |

## 后续照应与自由调查

盒内的“前批器材，已交”回应图上的“器材先交”，草鞋的候同行记录补充后批得到的照应，最终回执上的“接应：改在背风处”再与新点旁注对应。

前面的剧情按先看名单、再看行军图的顺序叙述。若先进入行军图，玩家仍可凭本件完整的“转三，后随二人”读懂后批安排；若已经调查电池盒，则并排核对“先交”与“已交”，继续查找后随二人的记录。已找到的结果保留在调查中。
