# 第五件：饭碗——另存的那一半记录

> 原创数字叙事物件。借碗、留饭、记号与交接记录属于故事设定。

## 剧情流程

草鞋上的小票写着“候后随二人同行”。材料的用途已经查清，照应的安排也有了依据，但名单上的那个开口框还没有得到回答。

玩家打开饭碗，碗外包着一张折纸，外折面露出**“借碗记”**。翻看碗底，两处熟悉的框形痕迹映入眼帘：一处是**开口框**，另一处是**点框**。它们与名单上的记号相似，为什么同时留在这只碗上？

玩家先展开外包纸，沿着“借碗记”的栏题读下去：

> 借碗记  
> 转三，后随二人，留饭用。  
> 倒扣收放，底画开口框记待接；接讫另记点框。  
> 回执随碗交回。

**“转三，后随二人”**将这只碗与前面的任务连在一起。它被借来留饭，倒扣收放时，从底部便能辨认记号。开口框记录待接，接讫后另记点框；两个记号可以先后留在同一只碗上。

最后一行的**“回执随碗交回”**尤其醒目。名单上的“回执另存”以及“随借〔缺失〕交回”，在这里有了可追查的对应。玩家先将这句话记下，再回到碗底拓印两个记号。

借碗记已经说明两个记号分别代表什么：开口框记待接，接讫后另记点框。碗底同时出现两处痕迹，正说明这只碗先后经历留饭与完成交接；记号本身不提供年代，也不需要排出先后。

翻过展开的外包纸，另一面显出完整的**转送回执**：

> 转送回执  
> 任务：转三  
> 接应：改在背风处。  
> 后随二人，已接。  
> 留饭一碗，交讫。

从名单上的“待交接”，到草鞋小票上的“候同行”，玩家终于读到了**“后随二人，已接”**。纸上同时写着改后的接应处与留饭交讫，答案已经出现，接下来要确认它与手里的记录对应。

玩家将回执和名单并排放置。**任务编号**同为“转三”，**接收事项**同为后随二人；移动到纸边比较，回执一侧的**裁口**与名单下端的残边接合，边缘转折逐处对应。这就是名单说明中另存的那份记录。

再对照行军图，回执上的“改在背风处”对应箭头指向的新接应点。旧点停用之后，接应在改后的地方有了结果。电池盒里的领出联与草鞋上的领用联补齐中间的经过：器材已交，一段备用背带用于补履，并有留组照应后随二人同行的安排。

名单上的**开口框**仍然保留。它曾让人以为任务停在那里，如今旁边放着另一份更后面的接收记录，旧记号便有了完整的上下文。纸上的缺字也保持原样，借碗记已经说明了回执怎样交回。

五件物品的记录终于联系起来。玩家保存核对结果：这项任务经过接应改点与分批安排，有器材交接、材料补履和留组候同行的记录；最终回执确认，后随二人已在改后的接应处被接收。

终章中，名单与回执并列，其他物件的相关记录可逐项回看。玩家从五件中选择一件陈列，在空白展签前写下自己的理解：

> 你希望下一位观看者注意到什么？

## 玩法

饭碗在前四件任意三件建档后开放。玩家可自由翻碗、展开外包纸、查看正反面或拓印，前面的叙述是一种推荐观察顺序。纸上的回执随时可读，不以拓印成功为解锁条件。

### 双记号拓印

玩家拓印碗底两处记号，按`rubbingIds`记录完成情况，重复拓印不新增记录。借碗记说明记号用途，因此拓印只确认“这只碗先后留下两种状态记录”；人员接收的结论由回执与关联记录说明，不由记号本身承担。

### 回执核对与建档

玩家并排查看回执和已建档资料。裁口比较沿用局部观察与并排对照，不增加必须严丝合缝拖动拼纸的关卡。

| 已调查资料 | 与回执核对什么 |
| --- | --- |
| 名单 | “转三—后随二人”、另存说明、裁口与原待交接状态 |
| 行军图 | 接应改到背风处，器材和人员分前后批安排 |
| 电池盒 | 前批器材已交，一段备用背带为“转三”领出，余带续用 |
| 草鞋 | 同项材料领用、补履二只，以及留组候同行的安排 |

此处容易产生的误判是：“名单仍是开口框，所以任务并未完成。”玩家需要将名单与另存回执放在一起，区分较早的待交接记录与后来的接收记录。确认结果后，原名单保持原样。

四份资料齐备后，玩家可以保留完整判断：

> “转三”在接应改点后按后批安排。前批器材已交，一段备用背带用于补履二只，并有留组照应后随二人同行的记录。另存回执确认，后随二人已在改后的接应处被接收。

如果饭碗是第四件打开，玩家照常读到“已接”，完成拓印并保存进度。界面列出缺少的前置资料，待其建档后再核对完整经过。已有结果保留，后续调查回答它怎样发生。

### 终章与展签

五件建档后，回看已保留的任务经过及各自依据，再任选一件陈列。展签输入保持空白，仅显示“你希望下一位观看者注意到什么？”，最多50个Unicode字符，也可留空。票据呈现所选物件、原创标识、建档状态与玩家文字。

## 提示

提示由玩家主动查看，先指向记录位置，再提醒对照依据。

| 卡住的位置 | 第一次提示 | 再次提示 |
| --- | --- | --- |
| 不理解两个框形记号 | 外包纸露出的“借碗记”说明了这只碗的用途。 | 看看待接时与接讫后分别怎样记。 |
| 只看见借碗说明 | 展开后的纸还有另一面。 | 翻面查看栏题，找找有没有交接内容。 |
| 读到“已接”，但不确定属于哪项任务 | 先核对编号与接收事项。 | 再将纸边与名单下端裁口并排比较。 |
| 仍因名单开口框而判断未完成 | 名单背面说明回执存在哪里？ | 让名单与另存回执并排，看两份记录各自写了什么。 |
| 不知道为什么还要查其他物件 | 回执写明结果，前面的记录解释经过。 | 看待补资料中缺哪件，再核对相应的安排或用料记录。 |

名单尚未调查时，提示只指向待补的名单资料，不展示其中尚未读到的具体文字。

## 线索与道具文字

### 碗底与外包纸

| 位置 | 可见内容 |
| --- | --- |
| 碗底一处记号 | 开口框 |
| 碗底另一处记号 | 点框 |
| 外包纸折起时 | 露出“借碗记”栏题 |
| 展开纸张的一面 | 借碗用途、记号说明与回执归还说明 |
| 另一面 | 转送回执的任务、接应处、人员接收及留饭交讫文字 |
| 回执一侧纸边 | 与名单下端残边对应的裁口转折 |

两只记号的形状与名单上的图例一致，用途由借碗记说明。碗的材质与制作年代保持未定；记号不用于推算年份、物主或修补次数。

### 借碗记

> 借碗记  
> 转三，后随二人，留饭用。  
> 倒扣收放，底画开口框记待接；接讫另记点框。  
> 回执随碗交回。

### 转送回执

> 转送回执  
> 任务：转三  
> 接应：改在背风处。  
> 后随二人，已接。  
> 留饭一碗，交讫。

接收人数以“后随二人”为据，留饭数量以“一碗”为据；记录没有进一步说明各自分食的方式。

## 伏笔回收

| 前面留下的线索 | 在本件怎样得到回应 |
| --- | --- |
| **名单的开口框与状态图例** | 借碗记说明另记点框的用途，回执写出“已接”；旧名单作为较早记录保留 |
| **“回执另存”与裁口** | 找到带有同项编号、事项且纸边相接的转送回执 |
| **“随借〔缺失〕交回”** | 借碗记明确“回执随碗交回”，原缺字保持缺失 |
| **改在背风处接应** | 回执登记同样的改后接应处 |
| **领出联、领用联与候同行** | 前四件已解释材料和照应经过，本件补上后随二人的接收结果 |

这些记录查清的是这一次原创交接任务。人物姓名与之后的经历仍没有记载，结局停在有依据的接收结果与玩家自行填写的展签。
