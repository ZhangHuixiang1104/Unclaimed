# 开发优先级与验收

当前仓库已有前后端与完整页面骨架，不再执行“从零创建 app／本地存档／前四件自由”的旧计划。[08当前分章方案](08当前分章设计与运行口径.md)是剧情与创作依据；[01总体架构](01总体架构.md)是实际技术入口。

| 优先级 | 工作 | 可验收标准 |
| --- | --- | --- |
| P0 已实施基础 | 五件独立谜题、顺序解锁、史实/虚构分区、旧档版本保护 | 前端可构建；其他四件不承接名单的“转三”任务；旧版云存档不被自动当作新版通关 |
| P1 已接入 | 名单道具图、拼合清泥、三幕故事与四站史实 | 本轮鼠标与键盘流程、故事卡焦点及等待文字对比度已实测；史实终审与图版权利待验收 |
| P2 已接入 | 地图／电池盒／草鞋专属操作与史实展柜 | 地图正面线索和背注核对分别完成；电池盒与草鞋完整手感待试玩 |
| P3 已接入 | 饭碗展开包纸、转碗、翻底扫光与史实展柜 | 五件归档后进入终章；浏览档案室不改写已生成票据的物件与留言 |
| P4 验收中 | 章节索引双层表达、来源、视觉／键盘验收 | 连线为调查顺序；锁定史实不剧透；研究照片当前进入构建，发布前仍须逐图核权 |
| P5 待做 | 多人试玩、公开部署安全、说明书和真实演示视频 | 新账号从注册到终章独立走通；后端、账号、素材与视频一致 |

本轮体验修复已通过前端 52 项测试、后端 13 项测试及生产构建。隔离数据库浏览器验收覆盖名单键盘全操作及鼠标拼合／擦泥、故事卡焦点、地图正背核对、票据选择保留、会话失效后恢复、旧档退出、多页草稿保护及跨账号拒写。五章完整真人试玩、移动端、公开部署及 Windows 启动脚本运行尚未验收。后续检查仍用 `npm run test`、`npm run build` 与 `python -m unittest discover -s backend -p 'test_*.py' -v`。
