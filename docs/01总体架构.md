# 总体架构与页面职责

本文件描述当前仓库和已确认的实施方向。现行剧情以[08当前分章方案](08当前分章设计与运行口径.md)为准；06、07 中的五件“转三”串联剧情已废弃。比赛原通知以主办方文件为准。

## 产品边界

玩家先注册／登录，随后作为档案保管员按 **名单 → 行军图 → 电池盒 → 草鞋 → 饭碗** 调查五件虚构物品。五件各有故事与待解问题；“转三”只在名单章节，不作为其他物品的共同任务。土城真实手迹、遵义与四渡赤水、通信保障、行军生活等历史主题在独立史实页阅读，不是虚构道具的出处证明。路线索引中的折线仅表示调查顺序。

## 实际技术底座

- `frontend/`：Vue 3、TypeScript、Vite、Vue Router、Pinia、SCSS；物件、线索及史实主题目前为本地只读配置。
- `backend/`：FastAPI、SQLAlchemy、SQLite；注册／登录、HttpOnly Cookie、按账号隔离的云存档、乐观锁修订号。
- 账号云存档仍是正式进度来源。前端修改进度时自动保存；若网络或后端暂时失败，仅将该账号的未同步游戏进度暂存在当前浏览器，重连时按云端修订号补传。暂存不含密码，云端确认后即清除；版本冲突必须由玩家选择，不能静默覆盖。旧版存档另有 `contentVersion` 保护，手动下载备份后才可开启新版。
- 现有路由：`/account`、`/`、`/archive`、`/object/:objectKey`、`/history`、`/history/:objectKey`、`/ending`、`/ticket`、`/about`。未登录深链先到账号页；史实详情及终章按进度封存。

## 页面跳转

`/account → / → /archive → /object/list → /history/list → /object/map → /history/map → /object/battery → /history/battery → /object/shoes → /history/shoes → /object/bowl → /history/bowl → /ending → /ticket`。每件在虚构故事保存后才出现独立史实按钮；阅读四站后建档并开放下一件。饭碗不再补写名单剧情。

## 当前实现与目标差异

目前三处痕迹通过侧光／透光／放大镜及标记找到；物件是可读文字与 CSS 示意。名单拼合清泥、饭碗拓印、完整的多视角图像和部分历史来源仍待制作。不能把后续目标写成已完成功能。PC 端为当前优先平台，延续深绿夜间工作台与暖纸材料，不另建一套冷灰主题。
