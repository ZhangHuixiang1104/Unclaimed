# 长征失物招领处：游戏剧情流程

玩家直接调查五件物品，通过观察、复原与交叉核对，还原一项长征途中照应任务的经过。

五件物品、任务编号、记录纸、标记与交接事件均为原创；历史背景另附来源。本文包含完整剧情与谜底。

## 1. 玩家究竟要解开什么

一张转送名单上，前两项已有交接记录，最后一项“后随二人”却停在“待接”。与名单一起保存的，还有改过路线的行军图、拆换过背带的通信器材示意盒、两只大小不同的草鞋，以及一只饭碗。

**最后一项交接完成了吗？这几件东西为什么会放在一起？**

玩家从物品上的记号入手，先确认编号对应的任务，再区分“器材先交”和“人员后随”的记录。接应地点变更、背带被拆作补料、为后随者留饭，都属于同一项任务的不同环节。最终，饭碗附带的回执与名单残边吻合，补上“后随二人已接”的结果。

这项任务经历了改点、分批、调拨物料补鞋与留饭接应，最后由回执确认完成。

## 2. 故事经过与谜底

故事设在长征途中的一个转送片段。队伍正在行进，一组随队照应人员负责把器材、备用物料和两名后随人员送到接应处。

名单记着三项任务。“转三”是其中第三项的临时编号，指向两名后随人员。纸上附有状态记法：开口框表示待交接，框内加点表示已有接收记录。

原先约定的接应点无遮蔽，不宜久候。接应安排改到背风处，前批先送器材，后批照应两名后随人员。名单上的前两项已有接收记号，第三项仍记为待交接。

器材交接后，备用背带被领走一段，登记在“转三”的修补用料项下；余带补接固定带，器材继续搬运。随草鞋保存的领用联写着“补履二只”，并注明“留一组照应，候后随二人同行”。两处记录连起来，呈现材料从器材备用物料转为行进补料的经过。

接应处借用一只碗留饭，借碗记上注明“转三”和“后随二人”。碗底沿用这组记录的状态记号，供倒扣收放时辨认用途：待接时画开口框，接讫后另记点框，两处痕迹因此同时留在碗底。交接完成后，回执记下“后随二人，已接。留饭一碗，交讫。”，随借碗交回。它与名单的任务编号、事项和裁口对应，给出接收结果。

这些物品最终作为同一项转送任务的记录包留在一起。它们有的被反复使用，有的在某个环节被借用，共同记录了多人接力完成的一件事。

## 3. 标记与工具怎样进入游戏

标记来自物品在转送、领料和交接中的用途。玩家通过记录内容辨认含义，再核对不同物件之间的联系。

| 可见内容 | 最初能提出的问题 | 在故事中的实际用途 |
| --- | --- | --- |
| 开口框与点框 | 同一栏里的框形记号为什么不同？ | 转送记录的状态标记，含义由名单图例提供 |
| “转三”与随行小票 | 这是物主、部队，还是一项任务？ | 第三项转送任务的编号；靠栏题、记录内容与回执核对 |
| 地图的旧点、改点箭头和前后批旁注 | 接应点为什么变了？ | 交接安排的变更 |
| 背带裁口、补料纹路与领料数量 | 器材为什么少了一段备用背带？ | 材料转作补鞋，领料与用途记录串起去向 |
| 碗底双记号与折叠回执 | 两个记号为何留在同一只碗上？它与“转三”有什么关系？ | 借碗记说明留饭与记号用途，回执确认交接结果 |

工具沿用观察台：放大、翻面、展开、有限清理、拓印、资料对照。工作台可并排显示已经发现并建档的线索卡，供玩家自行比对、整理调查笔记。四渡时序等历史内容作为可选背景阅读，不占主线调查。

随物小票、图例和回执作为物件的辅助资料呈现。所有符号都有可读文字说明和键盘入口。

## 4. 实际游玩流程

以下按推荐顺序写出玩家看到什么、做什么以及发现什么。前四件仍可自由调查，顺序适配见第6节。

### 序幕：一项没有回执的任务

屏幕直接进入工作台。名单、行军图、电池盒与草鞋可以打开，饭碗显示“完成任意三件建档后，可核对这件关联物品”。

开场只给一张任务卡：

> 几件物品与一份残缺的记录留在一起。
> 检查物品上的痕迹，找出接应的经过与结果。

五件均标示“原创数字叙事物件”，来源说明可随时查看。符号含义与任务结果随调查逐步揭示。

### 第一段：名单——记号记的是什么

完整剧情、道具文字与调查过程见[第一件：名单——记号记的是什么](剧情/第一件：名单——记号记的是什么.md)。

三片残纸散在台上，露出框形记号和“转三”，栏题尚不完整。前两个框内有点，第三个框开着口。

玩家沿折痕、纸边与笔画拼合，读出“转送事项”栏题。三行编号依次为“转一”“转二”“转三”，第三行完整写着“后随二人”。栏位和重复编号让玩家确认，“转三”是第三项转送任务。

玩家清理纸面，辨认已有字迹，再翻面查看图例：“开口框：待交接”“框内加点：已有接收记录”。下端裁口旁完整写着“回执另存”，下一行是“随借〔缺失〕交回”。姓名残栏与缺字保留原样。

玩家保留两项判断：“转三”是后随二人的转送任务；当前名单把它记为待交接，并注明回执另存。

建档后的当前问题：

> “‘转三’是后随二人的转送任务。它的接收记录在哪里？”

### 第二段：行军图——接应点为什么被划掉

独立剧情见[第二件：行军图——接应点为什么被划掉](剧情/第二件：行军图——接应点为什么被划掉.md)，以阅读叙述呈现调查经过、道具文字与线索发现。以下记录具体流程、分层提示、判断反馈与自由顺序衔接。

#### 一、初见：一个被划掉的点

行军图摊在台上，背面夹着一张折起的小纸。纸边露出“转三”，旁边能看见一个被打叉的圈点。折进去的部分尚未展开，圈点附近的线条在折边处中断。

已经调查名单的玩家，会认出“转三”这个任务编号，想查看它是否留下了接收记录。先进入行军图的玩家，也可以从被划掉的圈点开始调查。

玩家放大纸边，查看圈点和叉线。此时容易产生一个猜想：这个点被划掉，是不是接应取消了？画面先呈现异常，玩家可以带着猜想继续观察。

#### 二、展开：线条还有另一端

玩家翻到背面，展开小纸。原来在折边处中断的线条接了起来：一支箭头从打叉圈点旁引出，指向另一处未打叉的圈点。两端和箭头方向同时可见。

展开使用现有的局部观察操作，折进去的文字随纸面展开出现。这里没有需要猜回的缺字，所有纸面内容均可直接查看。

小纸上方的标题是“接应安排”。下方图例写着：

> 圈点：接应处  
> 打叉：旧点停用  
> 箭头：改定接应处

玩家先看箭头从哪里起、在哪里结束，再对照图例。“旧点停用”解释被划掉的位置；箭头末端另有接应处，说明接应安排仍有下文。

#### 三、读旁注：为什么换到那里

玩家沿箭头回到旧点，再查看新点，两处旁注分别由短引线连到对应圈点。引线没有箭头，只把文字连向位置。

| 纸面位置 | 可读文字或痕迹 |
| --- | --- |
| 上方标题 | 接应安排 |
| 旧点 | 圈点上打叉；旁注“无遮蔽，不宜久候” |
| 两点之间 | 从旧点旁指向新点的单向箭头 |
| 新点 | 未打叉的圈点；旁注“改在背风处接应” |
| 下方图例 | 圈点为接应处，打叉为旧点停用，箭头指向改定接应处 |

“无遮蔽，不宜久候”解释旧点为什么不用；“改在背风处接应”给出新安排。玩家由两处旁注与箭头共同确认：接应位置改变了，原因是旧点不适合久候。

这也排除了最初的“接应取消”猜想：箭头终点明确写着“接应”。只看旧点的叉线会误判，把箭头两端连起来读，才得到完整安排。

#### 四、核对分批：谁先交，谁后随

新点旁还有一条短引线，连到下方的两行记录。两行外侧画着同一个括线，括线顶端注明“两批均往改后接应处”。玩家顺着引线向下看，将新点与分批记录联系起来。

> 两批均往改后接应处

| 批次 | 转送安排 |
| --- | --- |
| 前批 | 器材先交 |
| 后批 | 转三，后随二人，改点接应 |

“转三”和“后随二人”落在同一行，与名单上的对应关系一致；“前批”“后批”分别位于两行左侧。共同括线说明，两批前往同一处改后的接应位置。

玩家已经读过名单时，可以并排查看“转三—后随二人”，确认这张纸记录的是同项任务的接应安排。没有读过名单时，本行完整文字也足以读懂后批的对象。

这里还容易产生第二个误判：“器材先交”是不是说明器材已经交到了？表头写的是“转送安排”，两行文字没有接收签记。玩家当前读到的是先后安排，实际交接结果仍需另一份记录。

#### 五、提示与判断：用线索排除猜想

提示由玩家主动打开。第一次只指向尚需观察的位置，再次请求才指出应对照的文字；玩家自行决定保留哪些判断。

| 卡住的位置 | 第一层提示 | 再次提示 |
| --- | --- | --- |
| 只盯着被打叉的点 | 这条线在折边处断开了，展开后看看另一端。 | 对照图例，沿箭头找到终点，再读终点旁的文字。 |
| 找到了新点，却不清楚改点原因 | 两个圈点各连着一条旁注。 | 旧点为什么“不宜久候”？新点注明了什么条件？ |
| 不清楚两批分别去哪里 | 看看两行记录外侧的括线连着哪里。 | 读括线顶端，再分别核对“前批”和“后批”所在行。 |
| 把安排当成交接结果 | 先看这张表的栏题，再找接收文字。 | “器材先交”写在“转送安排”下，纸上是否另有“已交”或“已接”？ |

建档时列出四项判断，由玩家结合纸面证据决定是否保留：

| 判断项 | 与线索的关系 |
| --- | --- |
| 旧接应点因无遮蔽而停用，改在背风处接应。 | 可保留：旧点旁注、新点旁注及改点箭头共同支持。 |
| 两批均往改后接应处，前批安排器材先交，后批安排接应“转三”的后随二人。 | 可保留：共同括线、批次栏和两行安排共同支持。 |
| 旧点被划掉，说明这次接应已经取消。 | 错误项：只看到了旧点；箭头终点仍写着“接应”。 |
| 仅凭这张图，已经可以确认前批器材交到了新点。 | 证据不足项：“器材先交”是安排，尚无实际交接记录。 |

上表的线索解释用于描述调查逻辑，选择界面只呈现判断文字。选择错误或证据不足项后，反馈引导回看对应位置：“再看箭头终点的旁注”或“再看批次表的栏题”。玩家可继续观察并修改选择，已有线索保留，不扣分、不重置调查。

#### 六、玩法与后续照应

正面的历史路线可用阶段按钮或时间滑块查看，附有出处与时间卡，作为可选背景阅读；背面的小示意为原创接应记录，是本件调查主体。背面随时可观察，背景阅读与接应记录分别查看。

| 本件线索 | 本件中的发现 | 后续照应 |
| --- | --- | --- |
| 打叉旧点、改点箭头与两处旁注 | 旧点停用，接应改到背风处 | 回执上的“接应：改在背风处”核对最终接收地点 |
| “前批：器材先交” | 器材被安排先交，结果待查 | 盒内“前批器材，已交”补上实际交接记录 |
| “后批：转三，后随二人，改点接应” | 后随二人属于同项任务的后批安排 | 草鞋上的候同行记录补充照应过程，回执确认后续接收 |

玩家保存两项有据判断后返回工作台。若尚未读到器材交接记录，留下的问题是：

> 接应点改了，器材被安排先交。后续物件留下了什么实际交接记录？

若已调查电池盒，则并排回看“器材先交”与“前批器材，已交”，再按已有资料继续核对后随二人的记录。

### 第三段：电池盒——少掉的一段去了哪里

独立剧情见[第三件：电池盒——少掉的一段去了哪里](剧情/第三件：电池盒——少掉的一段去了哪里.md)。独立稿先连贯叙述调查经过，再解释玩法、提示与线索；以下记录发现顺序和交互反馈。

#### 一、观察：带子是否都用来修盒子了

玩家先看见固定带的新旧接头，再翻看备用背带的齐整末端。放大时，可比较常受摩擦位置的散开纤维与另一处较齐整的边缘。痕迹让玩家产生“备用背带曾被裁取”的猜想，具体用途仍需纸面记录。

固定带已有接补，容易让人认为备用背带全用于修盒子。这是本件第一个可检验的猜想。盒内折纸露出“器材交接”栏题，引导玩家展开读取；纸面观察随时可用。

#### 二、读交接记录：先交有了结果，余带留下疑问

展开后先读上半部：

> 器材交接  
> 前批器材，已交。  
> 余带补接固定带，续用。

“前批器材，已交”与地图上的“器材先交”相互对应。接着，玩家用“余带补接固定带”核对接头。“余带”解释剩余材料的用途，同时引出裁下部分去了哪里的疑问。

#### 三、读领出联：找出材料的另一个去向

纸张下半部有独立栏题，任务、材料和数量分别成行：

> 修补用料·领出联（器材交接后）  
> 任务：转三  
> 材料：备用背带  
> 数量：一段  
> 领用联随修补物存。

一段备用背带在器材交接后领给“转三”作修补用料，余带则留作固定带接补。上半部的“余带”与下半部的“一段”共同解释材料的两个去向，修正“全用来修盒子”的猜想。

“转三”再次把调查引向后随人员，但“已交”属于器材交接栏，“转三”属于修补用料栏。玩家需区分器材接收与材料领出，尚不能由本件确认人员已接。

领出联的末行把下一步指向“修补物”及其领用联。具体用途留给后续物件揭示，本件只给出用于比对的任务、材料、数量三项。

#### 四、提示与判断反馈

| 卡住的位置 | 第一层提示 | 再次提示 |
| --- | --- | --- |
| 只看到带子破旧 | 比较固定带常受摩擦的位置与备用背带的末端。 | 看看散开的纤维和齐整边缘，再找纸上有没有材料用途记录。 |
| 认为背带全用来修盒子 | 回看“补接固定带”前面的两个字。 | “余带”说明的是哪一部分？再读下方领出联的数量栏。 |
| 混淆器材交接与人员接收 | 分别看看上半部和下半部的栏题。 | “已交”的对象是什么？“转三”下面登记的又是什么？ |
| 不知道接着查什么 | 领出联的最后一行说明了另一联放在哪里。 | 哪件物品既有修补痕迹，又可能保留领用小票？ |

提示由玩家主动查看。建档判断如下，解释列用于流程说明，选择界面只呈现判断文字：

| 判断项 | 依据或反馈 |
| --- | --- |
| 前批器材已有交接记录。 | 可保留：“器材交接”栏明确写着“前批器材，已交”。 |
| 一段备用背带在器材交接后为“转三”领出作修补用料，余带补接固定带后续用。 | 可保留：领出联的时间、任务、材料、数量与上半部续用记录共同支持。 |
| 备用背带全部用于接补本盒固定带。 | 错误项；引导重读“余带”及领出联的数量。 |
| 前批器材已交，说明“转三”也已完成接收。 | 证据不足项；引导分别核对两组栏题与记录对象。 |

玩家可返回观察、修改选择，保留已有线索，不扣分、不重置调查。

#### 五、后续衔接

本件不设接线、组网或发送练习，读完盒内两组记录即可继续。先看电池盒时，本件栏题足以解释交接与领料；名单建档后，再将“转三”与后随二人核对。草鞋已建档时，直接对照领出、领用两联的任务、材料和数量，继续追查人员接收结果；若回执也已读到，则用本件补齐任务经过。

尚未发现领用记录时，建档后留下的问题是：

> 一段备用背带领去修补了。哪件物品保留着它的领用记录？

### 第四段：草鞋——旧补料的来处

独立剧情见[第四件：草鞋——旧补料的来处](剧情/第四件：草鞋——旧补料的来处.md)。独立稿先连贯叙述调查经过，再解释玩法、提示与线索；以下记录具体发现顺序和判断反馈。

#### 一、翻看鞋底：找到修补物

两只大小不同的草鞋并排放着。玩家翻到鞋底，发现一处与草编不同的带状旧补料，跨过断开的编结，两端固定在较完整的位置。大小差异可以引起注意，补料与断口才是本件的调查入口。

已看电池盒时，玩家可联系“领用联随修补物存”，寻找伴随记录；先看草鞋时，则从旧补处和鞋侧小票查起。小票纸边露出“领用联”，展开即可读取，观察不以修补练习为前置。

#### 二、展开领用联：对上材料，读出用途

小票正面写着：

> 修补用料·领用联  
> 任务：转三  
> 材料：备用背带  
> 数量：一段  
> 用途：补履二只。

任务、材料和数量与盒内领出联逐项对应，新增的用途栏解释了那段背带去做什么。“补履二只”意为修补两只鞋，玩家可回看补料跨过断处的形态。纸面三栏和用途承担关联，纹路只辅助观察。

两只鞋大小不同，容易让人把它们直接分配给两名后随人员。核对用途栏可知，“二只”统计修补的鞋，记录没有登记各自的穿用者。

#### 三、翻到背面：用料之外还有人在等

小票背面露有字迹，翻面后读到：

> 留一组照应，候后随二人同行。

“后随二人”与名单事项及地图后批记录对应；“留一组照应”补充人员安排。由此，先交器材、领出材料和留下照应成为可以相互核对的任务环节。

玩家再读“候”字：这是等待同行的安排，尚未出现人员接收记录。草鞋回答材料用途及照应安排，名单留下的回执仍待寻找。

#### 四、提示与判断反馈

| 卡住的位置 | 第一层提示 | 再次提示 |
| --- | --- | --- |
| 只注意到鞋的大小 | 翻到鞋底，看看草编之外还有什么材料。 | 沿补料边缘，看它压住了哪处断口。 |
| 仅凭纹路认定来源 | 鞋侧的小票露出了什么栏题？ | 展开领用联，与已找到的领出联核对任务、材料和数量。 |
| 读完用途便离开 | 小票背面还有字迹。 | 翻面看看，除了材料用途，还留下了什么安排？ |
| 把鞋的数量当成身份 | “二只”写在哪一栏？ | 用途栏数的是修补的鞋，哪里记着各自的穿用者？ |
| 把同行安排当成到达 | 留意“后随二人”前面的那个字。 | “候”说明正在等待，接收完成还需要怎样的记录？ |

提示由玩家主动查看。若尚未发现盒内记录，材料来源提示只引导读本件小票，保留以后对照的方向。

| 判断项 | 依据或反馈 |
| --- | --- |
| 领用联记着一段备用背带用于“转三”的补履二只。 | 可保留：任务、材料、数量与用途四栏完整可读。 |
| 小票背面记着留一组照应，候后随二人同行。 | 可保留：背面文字直接说明安排。 |
| 两只鞋大小不同，因此能确定它们分别属于两名后随人员。 | 证据不足项；引导核对用途栏的计数对象与穿用者记录。 |
| “候后随二人同行”说明后随二人已经到达接应处。 | 证据不足项；引导重读“候”，再找接收文字。 |

选择界面只呈现判断项，解释列用于流程说明。玩家可回看、修改选择，已有线索保留。

#### 五、后续衔接

本件不设修补或行走练习，翻看补料、展开小票并对照两联即可继续。本件可独立保存补履和照应记录。电池盒已建档时再对照两联；名单与地图已建档时再对应任务对象和后批安排。若回执已先读到，则用本件补齐经过，回看同项接收记录。

尚未发现接收记录时，建档后留下的问题是：

> 有了补履和同行的安排，后随二人后来被接收了吗？

### 第五段：饭碗——另存的那一半记录

独立剧情见[第五件：饭碗——另存的那一半记录](剧情/第五件：饭碗——另存的那一半记录.md)。独立稿先叙述调查到终章的经过，再解释玩法、提示与伏笔回收；以下记录发现顺序、核对依据和提前进入时的衔接。

#### 一、初见：同一只碗上的两个记号

前四件任意三件建档后，饭碗开放。碗外包着折纸，外折面露出“借碗记”；翻碗可见开口框和点框两处痕迹。记号的差异引出用途与先后的问题。

翻碗、展开外包纸、查看正反面及拓印均可自由操作。以下按先看借碗说明、再查痕迹、最后读回执的顺序叙述；先翻到回执的玩家照常读到结果。

#### 二、读借碗记：留饭与归还说明

展开后，借碗记这一面写着：

> 借碗记  
> 转三，后随二人，留饭用。  
> 倒扣收放，底画开口框记待接；接讫另记点框。  
> 回执随碗交回。

“转三，后随二人”明确任务和用途，倒扣收放说明记号为何落在碗底。最后一行与名单的“回执另存”“随借〔缺失〕交回”形成核对方向。名单尚未调查时，先保存本件可读内容，不提前展示名单原文。

#### 三、拓印双记号：读懂碗底的状态记录

玩家拓印碗底两处记号，重复拓印不新增记录。借碗记已经说明：开口框记待接，接讫后另记点框，两处痕迹因此同时留在同一只碗上。记号不用于推算年份、物主或修补次数，实际人员接收仍须核对回执。

#### 四、翻面读回执：确认是哪一次交接

展开纸张的另一面写着：

> 转送回执  
> 任务：转三  
> 接应：改在背风处。  
> 后随二人，已接。  
> 留饭一碗，交讫。

“已接”回答结果，“转三”与“后随二人”说明接收对象。玩家并排放置回执和名单，核对编号、事项及裁口转折，再以地图的新点旁注核对接应处。裁口比较沿用局部观察与并排对照，不新增精确拖动拼纸关卡。

名单的原开口框保留，回执作为后续记录放在旁边。“回执随碗交回”回应残缺归还说明，原缺字保持缺失。人员接收与“留饭一碗”分别照文字读取，不额外推断谁吃了多少。

#### 五、提示与判断反馈

| 卡住的位置 | 第一层提示 | 再次提示 |
| --- | --- | --- |
| 不理解双记号 | 外包纸露出的“借碗记”说明了这只碗的用途。 | 看看待接时与接讫后分别怎样记。 |
| 只读到借碗说明 | 展开后的纸还有另一面。 | 翻面查看栏题，找找有没有交接内容。 |
| 无法确认回执归属 | 先核对编号与接收事项。 | 再将纸边与名单下端裁口并排比较。 |
| 因名单开口框而判断未完成 | 名单背面说明回执存在哪里？ | 将名单与另存回执并排，看两份记录各自写了什么。 |
| 不理解待补资料的作用 | 回执写明结果，前面的记录解释经过。 | 看缺哪件资料，再核对相应的安排或用料记录。 |

提示由玩家主动查看。名单尚未建档时，只指向待补的名单资料，不展示未读原文。

本件保留一个可检验的误判：“名单仍是开口框，所以任务并未完成。”反馈引导比较名单与回执各自的状态记录；玩家核对后修改判断，原物文字与记号均保留。

#### 六、核齐经过：从接收结果回到五件物品

| 对照资料 | 回执出现后要核对的内容 |
| --- | --- |
| 名单 | “转三—后随二人”、原待交接状态、另存说明及裁口 |
| 行军图 | 接应从旧点改到背风处，器材和人员分批安排 |
| 电池盒 | 前批器材已交，一段备用背带为“转三”领出，余带续用 |
| 草鞋 | 同项背带领用记录、补履二只，以及留组候同行的安排 |

如果饭碗作为第四件打开，玩家可以读到完整回执，完成拓印并保存进度。界面如实呈现“已接”，列出待调查的前置资料；补齐后再核对完整经过，不把已知结果改回未知。

四份资料齐备后，玩家自行保留完整判断：

> “转三”在接应改点后按后批安排。前批器材已交，一段备用背带用于补履二只，并有留组照应后随二人同行的记录。另存回执确认，后随二人已在改后的接应处被接收。

这次交接有了明确结果。人物姓名与之后的经历仍未记载，结尾由玩家选择陈列物件并填写展签。

### 终章：把事情接起来

五件完成建档后，终章展示玩家已保留的事件记录，按任务环节回看“待接—改点分批—领料补鞋—照应后随—接收交讫”。每一步都能回到对应物件查看依据；没有明确日期的记录保持相对关系。

名单上原来的开口框保留原样，回执并列放在旁边，展示玩家重新联系起来的两份记录。

接着，玩家选择五件中的任意一件陈列。输入区保持空白：

> 你希望下一位观看者注意到什么？

文字最多50个Unicode字符，也可留空。玩家自由选择陈列物品，并写下自己的理解。

票据呈现作品名、原创标识、所选物品、建档状态与玩家文字。

### 五件的连续调查

五件围绕“转三”的接收记录展开。前四件逐步查清任务、接应安排和照应经过，第五件用另存回执给出结果，并将原先分散的记录联系起来。

| 物件 | 本件回答的问题 | 衔接依据 | 调查推进 |
| --- | --- | --- | --- |
| 名单 | “转三”指什么，开口框记什么 | “转三—后随二人”和回执另存说明 | 寻找对应的接收记录 |
| 行军图 | 接应为何改点，前后批如何安排 | “前批：器材先交”，引向器材交接记录 | 查实际交接与后批经过 |
| 电池盒 | 前批是否已交，备用背带去了哪里 | “领用联随修补物存”，引向旧补料和小票 | 查具体修补用途 |
| 草鞋 | 材料用于补履，后批有留组候同行安排 | 同项编号与后随二人，重新对应名单 | 回到人员接收结果的主问题 |
| 饭碗 | 后随二人是否被接收，回执如何对应名单 | 编号、事项、改后接应处、裁口与归还说明 | 确认交接结果，核齐经过并进入终章 |

调查顺序与事件顺序分开理解。地图记录分批安排，名单保留前两项已有接收记录、第三项待交接的状态，盒内文字确认前批已交，并明确领料发生在器材交接后。玩家可以先见状态，再回查安排；没有把第二件当成第一件之后才发生的事件。小票上的“候同行”仍是安排，其写下时间与具体行动细节不另补日期。

读到草鞋时，材料的支线收束，接收记录的主问题回到前景。人员结局由后续回执给出；单件小游戏完成不代替证据判断。若饭碗已先打开，则改为补齐、核对上述经过，不重新隐藏已读结果。

五件围绕同一个原创转送片段相互关联。湘江、四渡赤水、通信保障、雪山草地与会师等历史背景作为各物件的资料入口分别阅读，故事接应小示意承载本次任务的地点关系。

## 6. 自由顺序与建档

五件沿用既有ID与互动。前四件自由调查，任意三件建档解锁饭碗，五件完成后进入终章。

前四件均可凭本件线索和资料独立完成必需判断。草鞋先看时，从领用联读出“备用背带”和“补履二只”；电池盒先看时，从领出联读出材料为修补领出。两件都看过后，玩家可核对两联。

工作台线索卡展示已发现并建档的内容与保留判断，供玩家进行早期对照。

各段末尾的问题随已发现的线索与已保留判断切换：问题尚待解决时给出调查方向，已有答案时引导回看依据。

| 当前调查情况 | 收束或对照方向 |
| --- | --- |
| 名单先看 | 保留寻找“转三”接收记录的问题 |
| 名单后看，且已读饭碗回执 | 核对编号、事项和裁口，寻找两份记录能否对应的依据 |
| 地图后看，且已有器材交接记录 | 对照“前批器材先交”的安排与“前批器材，已交”的结果；人员结果仍按已读证据处理 |
| 电池盒与草鞋任意一件先看 | 保存本件的领出或领用记录，后续与另一联核对 |
| 电池盒与草鞋都已看 | 对照同项任务、材料和数量，转向后随人员的接收结果；若回执已读，则回看它与该任务的关联 |
| 饭碗第四件先看 | 读取接收文字，列出待调查的前置资料，补齐后核对完整经过 |

饭碗设置四张`basis: story`的关联DocumentCard：

| 资料ID | `requiresArchivedObjects` | 对照内容 |
| --- | --- | --- |
| `bowl-compare-list` | `['list']` | 第三项编号、回执说明、裁口与状态图例 |
| `bowl-compare-map` | `['map']` | 旧点改到背风处，以及器材、人员的分批安排 |
| `bowl-compare-battery` | `['battery']` | 前批器材已交、备用背带一段领出与余带续用 |
| `bowl-compare-shoes` | `['shoes']` | 同项材料领用、补履二只与留组候同行 |

饭碗的最终必需命题ID为`bowl-handover`，其`requiredClueIds`为碗自身两条线索`bowl-marks`、`bowl-receipt`，`requiredDocumentIds`为上表四张关联资料。关联资料引用前置物件的具体线索ID。

饭碗作为第四件打开时，可完成拓印与本地观察并保存进度；前四件全部建档、四份关联资料齐备后，完成饭碗最终建档。待补资料明确指向对应物件。

重做任何前置物件，沿02撤销对应饭碗关联资料、依赖判断与饭碗建档，保留有效拓印。终章事件回看与工作台卡片由有效进度派生。

沿用现有内容结构：`Clue`承接可见痕迹，`DocumentCard`承接局部说明与饭碗关联，`Claim`承接玩家保留的判断，`takeaway`写本件结果与下一问题。

## 7. 剧情推进与主题

剧情由连续的证据缺口推进：名单确定任务和另存回执，地图说明接应安排改变，电池盒给出前批交接与材料领出，草鞋补上领用用途和照应安排，饭碗最终提供接收结果。先看到结果的玩家可回查经过；按推荐顺序调查的玩家则逐件缩小问题。关键发现落在可读文字或可见痕迹上。

长征主题进入因果与操作：路线变化需要重核接应安排，通信与器材需要有人保护、搬运和维修，有限物料需要调配，行进完成需要把后随者接上。玩家反复执行查看前后关系、比对记录、接续线索的操作。

历史背景分别呈现湘江、遵义与四渡赤水、通信保障、群众制鞋与雪山草地行进、会师，帮助玩家理解故事中的劳动与困难。历史总图与故事接应示意各自展示。

先行交接、照应人员、补料领用与接应记录共同构成结局，物件间的关联让玩家看见协作的过程。
