# 交互与视觉统一规范

以[前端设计系统](../frontend/DESIGN_SYSTEM.md)和现有全局样式为视觉实现依据；[08当前分章方案](08当前分章设计与运行口径.md)为剧情依据。本项目当前**PC 优先**，不切换为另一套冷灰 UI。

## 画面

首页、账号、档案室、检查台、章节索引、说明页统一深绿／近黑夜间背景、暖米色纸张、暗红印章与高对比度正文。展示标题可用宋体风格；中文正文、按钮、证据判断用清晰的无衬线字体；微小文字只限编号和辅助标签。不要通过降低正文透明度制造旧纸感。线索的“发现／推测／未知”必须有文字标签，不仅靠颜色。

## 核心互动

1. 五章使用各自物件和操作。名单拼片、清泥、正背三幕；行军图从正面发现四条改线线索，再阅读背注核对；电池盒、草鞋与饭碗各有专属观察步骤。
2. 名单三幕齐备后保存故事；其余四章观察齐备后选择有证据支持的展签。五章均使用现有故事与展签流程。
3. 保存故事后单独按钮揭露对应历史主题；四站标注“已浏览”，表示材料被打开。历史背景与故事内结论分区，材料卡标来源。
4. 各章只呈现本件物品的证据；饭碗刻痕不是名单回执，其他四件不得提前公布名单任务的结果。
5. `/history` 是**章节／史实索引**：连接线表示五件调查次序，不是地理路线。锁定章仅显示序号、进度和封存，不显示年代、地点和史实题目。

名单纸片可拖动，也可 Tab 聚焦后按 Enter／Space 对齐；选择轻拭工具后可拖动擦泥或使用清理按钮。三条热点支持键盘，故事卡打开时移入焦点，Tab 留在卡内，Escape 关闭后返回原入口。等待线索使用完整文字对比度。饭碗采用包纸、转碗、斜光观察。PC 完整流程仍须逐章检查字迹、点击区和遮挡。当前页面采用无音频交互。
