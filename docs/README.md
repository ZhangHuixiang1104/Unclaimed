# 长征失物招领处｜文档入口

> 当前统一口径：2026-10-17 修订。五件物品各有独立故事，按 **名单 → 行军图 → 电池盒 → 草鞋 → 饭碗** 顺序解锁。“转三”只属于名单章节，不是全作主线；历史资料另页阅读。

## 阅读优先级

1. [当前分章设计与运行口径](08当前分章设计与运行口径.md)：现行的故事边界、页面跳转、账号和待办；以此为准。
2. [名单专题入口](../stuffs/名单/README.md)：名单独立剧情、制作方案、史实研究与美术素材清单；游戏与史实分开。
3. [总体架构](01总体架构.md)、[数据与状态契约](02数据与状态契约.md)、[交互与视觉](03交互与视觉.md)、[内容与素材规范](04内容与素材规范.md)、[开发任务与验收](05开发任务与验收.md)：技术部分仍可参考；遇到剧情冲突以 08 为准。
4. [历史研究台账](research/01历史背景与日常物件.md)、[通信与素材来源](research/02通信技术与素材来源.md)：研究候选与待核事项，不等于已获图片授权。
5. [比赛要求](比赛要求.md)：赛事资料摘录；正式提交前按主办方原通知再次核对。

根目录的[早期参赛提案](../长征失物招领处参赛设计与开发计划.md)保留为创作过程记录，已不作为现行玩法、技术或史实节点依据。 `stuffs/名单/史实资料` 是专题来源底稿，不应随意改写为剧情正文。

## 当前程序与剩余工作

仓库已有 Vue 3／TypeScript 前端、FastAPI／SQLite 账号与云存档，注册或登录先于作品首页。现有检查台支持正反面文字示意、三处玩家自行标记的痕迹、五条候选说法、证据盖章、独立史实揭露与顺序建档。旧版云存档会提示下载备份并自愿开始新版，不能冒充新剧情进度。

**尚未完成**正式物件图片、名单拼合清泥、饭碗拓印、各章专属交互、四个历史主题的权威来源与授权图、真实浏览器多人试玩和公开部署安全验收。当前 CSS/文字物件是可玩的示意版本，不是已完成美术。运行方式和验证结果以[根 README](../README.md)及[前端 README](../frontend/README.md)为准。
