# 长征失物招领处

**为无名者保存一件东西。**玩家直接调查名单、行军图、电池盒、草鞋与饭碗，通过标记、改点记录、领料小票和回执，解开一项长征途中照应任务的经过与结果。没有代替玩家行动的现代主角或NPC对白。

五件物品与交接事件为原创数字叙事；真实历史背景、教学模型与虚构痕迹分开标识，不把虚构物件当真实馆藏。事件可以在故事内查清，未知姓名不代替剧情答案。

## 已定实施方向

- Vue 3＋TypeScript＋Vite静态单页，原生SVG/Canvas与二维物件图；五件完整、终章可达。
- 统一状态与事件，本地有版本存档、手动备份与安全导入；核心体验断外网后通过本地HTTP可运行。
- 原创物件串联同一项照应任务，交接结果由多件证据核对；历史背景逐条引用，四渡时序等史料内容作为可选背景阅读，不作线索门槛。
- 当前不引入账号、后端、联网统计、实时AI与复杂3D；在线托管仍可使用同一静态产物。
- 正式内容、素材许可与浏览器体验分别过门槛，不以依赖数量、证据条数或代码量证明质量。
