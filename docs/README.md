1. [当前分章设计与运行口径](08当前分章设计与运行口径.md)：现行的故事边界、页面跳转、账号和待办；以此为准。

3. [总体架构](01总体架构.md)、[数据与状态契约](02数据与状态契约.md)、[交互与视觉](03交互与视觉.md)、[内容与素材规范](04内容与素材规范.md)、[开发任务与验收](05开发任务与验收.md)：技术部分仍可参考；遇到剧情冲突以 08 为准。
4. [历史研究台账](research/01历史背景与日常物件.md)、[通信与素材来源](research/02通信技术与素材来源.md)：研究候选与待核事项，不等于已获图片授权。

[早期参赛提案](../archive/长征失物招领处参赛设计与开发计划.md)已归档到 `archive/`，保留创作过程记录。实施以现行分章方案与技术契约为准。`stuffs/` 按五件物品保存剧情、素材母版、研究底稿与来源清单。

## 当前程序与剩余工作

仓库已有 Vue 3／TypeScript 前端、FastAPI／SQLite 账号与云存档。五章均有专属物件操作、故事保存、独立四站史实与顺序建档，并接入终章和保管票据。名单支持鼠标与键盘；行军图正面线索和背注分别核对。账号存档保护、旧档迁移及本轮体验修复的验收记录见[开发任务与验收](05开发任务与验收.md)。

**尚未完成**五章真实浏览器完整视觉与手感验收、素材体积优化、史实研究图版的逐件授权、多人试玩和公开部署安全验收。五章均已有专属互动与原创后制示意，但这些示意不是馆藏原件照片。运行方式和验证结果以[根 README](../README.md)及[前端 README](../frontend/README.md)为准。
