# 内容、史料与素材规范

## 1. 三类内容各自可证明什么

本项目不是对真实失物、文物或无名者身份的鉴定。五件物品、转送任务、辅助记录、维修层和跨物件线索均为创作。玩家直接调查，不设现代主角或NPC对白；有据的长征背景与原创照应事件分开，虚构痕迹不证明真实经历。

| 内容性质 | 页面标识 | 可确认的范围 | 禁止的推断 |
| --- | --- | --- | --- |
| history | 历史背景／后人研究解释／亲历者回忆，按来源细分 | 有出处的具体事件、时间口径、生活背景或资料中的研究判断 | 由概括背景推出虚构物件真实存在、物主、部队、流转或牺牲结局 |
| story | 原创叙事线索／故事内判断 | 人工设定的可见痕迹与有限关联 | 把虚构姓名、笔迹、对话、家书、刻痕写成史料或真实档案 |
| model | 教学模型／模型内判断 | 规则设定下的拼合与排除 | 将容差、热区或示意坐标当历史测量或鉴定结果 |

basis与证据等级按02分别保存。每条命题都说明主体、时间/范围、来源性质和解释限度。历史“未知”不能靠作者补故事变成“已知”；故事的“可确认”旁边须显示范围。终章与票据也保留虚构说明。

## 3. 五件内容底稿与命题设计

下面明确叙事功能与问题方向，尚不是已经审核通过的最终卡片。内容作者先依据研究表写证据链，再由另一名成员复核事实与反馈，才进入content。

| 物件 | 要让用户发现的内容 | 必须包含的判断方向 | 对应史实回声 |
| --- | --- | --- | --- |
| list | 转送名单的任务栏、状态图例与另存回执 | 可确认故事内有待接任务与回执缺口；缺字/姓名留空，不将未闭合状态当牺牲记录 | 湘江背景及保存记录；原始表格形制另查 |
| map | 历史四渡按时序查看，原创接应安排另有改点与分批 | 真实行动变化有出处；原创改点记录可确认，不能证明后随者已到达 | 遵义与四渡；接应小示意不冒充真实军用图 |
| battery | 器材先交与备用背带转作补料的记录 | 任务记录与裁口属story，由实物痕迹与纸面记录核对；不设通信练习充当证据 | 通信器材保护、运输与保障 |
| shoes | 旧补料、小票与留组照应说明 | 可确认故事内记有补履和照应；材料相似仅辅助，不鉴定物主、不直接推到达 | 群众制鞋、艰难行进与互助 |
| bowl | 双记号、另存回执及前四件记录共同核对 | 可确认故事内改点分批、领料补鞋到接收交讫的任务链；真实人名、日期地点及此后经历未知 | 生活器具与分地点会师背景；交接不映射为会师现场 |

每件以少量关键线索和2—3个必需命题为起点，按06的事件推进安排，不凑固定矩阵。不得给五件都机械添加“物主未知”题，也不以纹路相似冒充独立证据。饭碗最终命题要求前四件四份关联资料，记录内容、编号与先后共同支持，不能把一次局部解谜直接变成历史确认。

任务编号、状态图例、改点说明、补料小票与回执文字统一标原创；不借真实人物说虚构遗言，不制作人物出场对话或历史录音。可选旁白只读操作与资料，不能替玩家发现线索或作判断；姓名缺失不妨碍查清故事内的交接事件。

## 4. 来源与审核记录

每条Source记录02规定字段：真实URL、标题、发布方、作者或null、网页日期或null、查阅日期、workId、类型、使用边界。网页发布时间、原刊期号、修改时间分开写，不能从URL补未知日期。

引用Citation.locator写章节＋段首关键词，纸本写书名、版本、页码；“见官网”“同上”不是合格定位。转载链按作品管理，共用同一电报/回忆录也需注明。官网权威不等于所有推断已被证实。

内容审核顺序：

1. 把事件事实、原作者分析、回忆转述与创作设定分开，标明来源实际读到哪里。
2. 针对关键日期、部队主体、因果与器材背景补独立核验；重复转载不增加佐证。
3. 先写命题再检查证据是否支持。acceptedLevels与三种反馈都逐条审阅，不能仅按两项/一项证据判断。
4. 记录冲突与取舍：例如二渡18—19日/18—21日、草地回忆年份、会宁/将台堡主体。未解决时缩小事实表述范围或采用无争议顺序，保留研究缺口；不得静默改日期。
5. 由未编写该条的成员审阅；单人团队请一名外部同学/老师核内容，不要求对方批准工具操作。内容完整再写发布数据，研究猜测不打包为正式事实卡。
6. 检查用户界面与录屏都明确展示虚构/教学范围。资料链接不可达时本地元数据与自撰摘要仍可读；不能复制原站全文做离线镜像。

审核记录至少有：命题ID、草稿、basis、支持来源及locator、未支持部分、冲突、取舍理由、复核人/日期、是否可发布。不在没有复核人的情况下填写虚构姓名或“已审核”。

## 5. 素材清单与采购优先级

本轮收集到的是资料与许可入口，尚未下载/制作发布素材、试听声音或观察馆藏图像细节。

| 素材组 | 必需产物 | 获取策略 |
| --- | --- | --- |
| 公共界面 | 档案箱/抽屉、检查台、路线总图、图标、票据 | 团队原创简化图形；先统一一件样板的比例与光源 |
| 名单 | 正背面、三片透明图、遮罩、辨字局部、状态图例与回执裁口 | 原创转送道具；栏题与回执说明实际可读，不编造真实烈士名单 |
| 行军图 | 固定地理背景、四段路线与时间卡；另附原创接应小示意（折叠前后、箭头、旁注、分批记录） | 史实图先核地名时序；原创改点旁注与真实地图分开，不复制受限图 |
| 电池盒 | 正背面、维修与裁口局部、器材交接与领料记录 | 原创器材示意；补料记录不作史料，不造型号、电文或教学节点图 |
| 草鞋 | 正面/底面、旧补料、领料小票正反面与照应记录 | 原创图/自制道具；补料图案需能比对，但不能单独鉴定来源或身份 |
| 饭碗 | 正底面、双记号与拓印、外包回执展开图 | 原创道具；回执编号、裁口与名单一致，不冒充其他时代馆藏 |
| 声音 | 翻纸、抽屉、风雨、布条、碗、字幕旁白 | 优先自录拟音；开放音效须条目许可＋试听通过 |
| 字体 | 正文字体与标题所需字重 | 原版思源字体官方OFL入口，锁定版本并随包留许可 |

每件先做正面、背面、关键局部和互动必需层，不因原提案列长表就一次性画齐全部装饰。预览用图不得进入最终验收；正式素材必须完整可见、尺寸可读、无生成水印或伪造馆章。

文件名采用`object_view_state.ext`，ID带物件前缀；图优先WebP/PNG，路线和图标用SVG。可编辑源保留在素材记录对应目录，发布副本才进入app/public/assets。未确定尺寸前不承诺统一体积，实际加载后测首屏与最大素材量。字体避免全字库、多字重无差别打包；若子集化需重新核命名/许可条件。

## 6. 使用权与资产审核

来源真实性与使用权分开登记。A01—A03的开放馆藏解决图像许可，不解决与长征的历史关联；A04风声是现代录音，尚未试听，不能称雪山实录。L05/L06字体可按OFL使用，需绑定最终下载版本。

每项资产在Asset之外的制作登记保留：文件ID与原始/发布路径、作者/机构、原页、许可URL或书面授权、使用范围、修改、署名、AI辅助范围、日期、图像/音频实检结果。原始记录不能只填“来自网络”。

`approved=true`必须同时满足权利、内容、技术三项：许可覆盖网站/视频/离线包用途；素材不误导真实性；实际文件已查看/试听并能在本地正常加载。许可入口已核验但未下载的资产仍不算approved。史料全文、官方照片、文物扫描与歌曲未获许可时继续原创，不先搬用。

自录配音获得表演者对网页、视频和离线包使用的同意；拟音排除背景版权音乐与私人对话。AI图只作为创作素材，登记工具与用途，绝不作为馆藏、史料或授权证明。

许可文本、必要署名随最终包提供，来源页与片尾区分“历史参考”“素材与工具”；不暗示纪念馆、作者或机构为项目背书。外部联系、申请授权、购买或发送信息不由本次搜集自动执行。

## 7. 已知研究缺口与实施门槛

- 电池盒技术与大渡河现场关联未知；使用原创示意与教学模型是明确的创作方式，不能宣传复原。
- 项目名单、草鞋交换、饭碗刻痕未对应真实馆藏；发布叙事可以保留未知，但不能伪造历史经历。
- 精确地理底图、分路与部分日期仍待核验；四渡作为可选背景阅读，可先用有来源的无争议范围，完整地图先过内容审核。
- H08回忆年份疑点、T01/T02编制差异和T06旧版标准范围都已记入研究；未消解前不使用相关精确值出题。
- 尚未得到官方文物图片再利用许可，未制作最终图/音频，未完成3人试用。

后续先完成一件内容与互动闭环，再扩展其余四件；终章所需五件均完整，不以“至少四件”规避最终验收。
