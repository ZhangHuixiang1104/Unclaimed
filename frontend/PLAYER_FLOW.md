# 玩家流程与剧情状态

本文件记录当前已实现的游玩顺序。首次进入先注册或登录；五件物品按档案编号依次开放，调查进度登录后保存在后端。

## 页面路径

| 页面 | 路径 | 进入条件 |
| --- | --- | --- |
| 档案员登记 | `/account` | 未登录时的首个页面；注册或登录后进入作品 |
| 首页 | `/` | 已登录 |
| 档案室 | `/archive` | 已登录；可预览五件物品 |
| 检查台 | `/object/:objectKey` | 第一件默认开放；其余须完成前一件归档 |
| 路线总览 | `/history` | 已登录；未完成节点隐藏地点和史实 |
| 史实详情 | `/history/:objectKey` | 对应物品已经归档；否则只显示封存页 |
| 终章 | `/ending` | 五件物品全部归档 |
| 保管凭证 | `/ticket` | 终章完成物品选择和留言后 |

物品键依次为 `list → map → battery → shoes → bowl`。每章完成后，检查台可直接进入本章史实详情，也可返回路线总览；史实详情提供下一章的档案室入口。

未登录时直接打开任何剧情路径，都会先跳转档案员登记页；验证成功后返回原本想打开的页面。已有有效会话的玩家可直接进入首页，不需要重复注册。云端进度出现冲突时，先在登记页选择保留哪份记录，再进入作品。

## 每件物品的通关条件

1. 在检查台选择观察工具，自己在物件上标记三处有效痕迹。未发现前没有带编号的线索点；干扰痕迹可能造成误判。
2. 三处痕迹齐全后，证据工作板打开五个候选问题。玩家对每个问题选择“收入”或“排除”，提交筛选；三个核心问题和两个无证据问题必须处理正确。
3. 为保留下来的三条结论盖“可确认 / 可推测 / 仍未知”印章。全部等级正确后，证据核验通过。
4. 此时才出现独立的“揭开史实档案”按钮。史实层展示本章历史背景、物证推断及未知边界。
5. 玩家点击“我已阅读，建立物件档案”，物品才被归档；路线节点点亮，下一件物品开放。

调查中的筛选与印章可以修改；修改筛选会清除此前的印章和核验结果。归档后的记录为只读，仍可回看检查台和史实层。

## 五章叙事接力

| 章 | 物品 | 调查问题 | 归档后公开的路线 | 引向下一章 |
| --- | --- | --- | --- | --- |
| 01 | 被雨水浸过的名单 | 痕迹能否找回姓名？ | 湘江之后 | 从姓名转向不断改写的道路 |
| 02 | 改了四次的行军图 | 哪些路线曾被使用？ | 遵义与赤水 | 道路变化需要消息传递 |
| 03 | 用布缠过的电池盒 | 维修痕迹说明什么？ | 大渡河畔 | 消息传递之后仍须行走 |
| 04 | 修补了七次的草鞋 | 是否出自同一使用者？ | 雪山草地 | 身份未知的物品可能流转 |
| 05 | 有两个刻痕的饭碗 | 刻痕能否对应具体人物？ | 会宁 | 五件物品共同进入终章 |

本作中的五件物品是艺术化叙事设定。路线背景与物件推断分开展示，不能把虚构物件当成已经鉴定的历史文物。当前史实页提供背景文案和材料接入位；正式参赛版本仍需为五个节点补齐经过核验的文献出处、图片来源和授权信息。
