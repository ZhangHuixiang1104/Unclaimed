# Unclaimed 前端

本目录为现有 Vue 3／TypeScript／Vite 前端，不是尚未创建的空项目。账号页先于首页；五件虚构物品依次解锁，史实另页公开。实际剧情与研发状态见[根 README](../README.md)及[玩家流程](PLAYER_FLOW.md)。

## 开发与检查

先按根 README 启动 FastAPI 后端，再在本目录运行：

```powershell
npm install
npm run dev
npm run test
npm run build
```

开发地址为 `http://127.0.0.1:4173`，`/api` 请求代理到本地后端。后端健康接口须返回当前 `saveContract`；旧后端进程需重启。云端未确认的游戏进度会暂存当前浏览器并在重连时补传，期间不要清理本站数据。构建产物在 `dist/`。

## 已实现与待做

已实现：路由、统一夜间档案视觉、注册登录、云端自动存档与版本保护、顺序解锁和独立史实揭露。名单章节已有拼片、清泥、三幕故事和四站史实；行军图已接入正反纸面、四层路线、隐藏观察区、侧光与描图尺、四段故事、展签核对和四站史实展柜。两章的线索与阅读进度随账号存档，均不使用通用「添加标记＋五题筛选＋盖章」。“转三”仅在名单章节；后三件仍暂沿用通用调查示意。
