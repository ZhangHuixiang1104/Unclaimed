# 长征失物招领处前端框架

这是《长征失物招领处》的 Vue 3 前端骨架。当前版本使用占位素材，已经跑通首页、档案室、通用物件调查、证据分类、通信样板、路线档案、终章和保管员票据。

详细填充方法见项目根目录的《前端框架填充说明.md》。

## 启动

```text
pnpm install
pnpm run dev
```

## 检查与构建

```text
pnpm run typecheck
pnpm run build
```

构建产物输出到 `dist`。

## 当前范围

- 已完成：页面路由、统一视觉框架、五件物品配置、本地存档、证据分类、通信关卡样板、响应式布局。
- 待填充：正式图片、史实内容、四件专属互动、正式音效、后端接口、海报图片导出。
