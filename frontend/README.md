# Unclaimed 前端

本目录为现有 Vue 3／TypeScript／Vite 前端，不是尚未创建的空项目。账号页先于首页；五件虚构物品依次解锁，史实另页公开。实际剧情与研发状态见[根 README](../README.md)及[玩家流程](PLAYER_FLOW.md)。

## 开发与检查

先按根 README 启动 FastAPI 后端，再在本目录运行：

```powershell
npm install
npm run dev
npm run test
npm run build
```

开发地址为 `http://127.0.0.1:5173`，`/api` 代理到后端。健康接口须返回 `saveContract: independent-chapters-v6` 和 `identityContract: account-bound-v1`；更新后重启旧后端。未同步进度按账号与页面实例隔离暂存；刷新发现草稿时用现有账号页核对，暂存期间保留本站数据。构建产物在 `dist/`。

## 已实现与待做

已实现：路由、统一夜间档案视觉、注册登录、账号绑定的云端存档与版本保护、顺序解锁和独立史实揭露。五章均有专属操作、故事保存及四站史实；名单支持键盘拼片、清泥与线索阅读，地图正面线索与背注分开核对。终章选择和留言保存为票据，首页及档案室浏览不会改写票据。五章均不使用通用「添加标记＋五题筛选＋盖章」；“转三”仅在名单章节。

待验收：五章完整 PC 真人试玩、手写字缩放、史实终审与研究图版授权、素材体积优化。当前图版与剧情保留原状；研究照片已经接入构建，产品使用权仍需逐图核验。本轮 52 项前端测试及构建通过，具体浏览器验收见[根 README](../README.md)。
