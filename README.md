# Unclaimed

> 主人未知，经历真实，共同保存。

**Unclaimed**（中文名：长征失物招领处）是一款以长征历史为背景的互动数字档案作品。玩家以档案保管员的身份观察遗留物件、修复线索、判断证据并完成归档，在无法确认物件主人身份时，依然保存真实发生过的经历。

## 当前进度

- 已完成 Vue 3 前端框架与整体视觉风格
- 已接通首页、档案室、物件调查、路线档案、终章与保管员票据
- 已实现线索发现、证据分类、本地存档和通信互动样板
- 当前使用占位素材，后续将逐件补充正式史料、图像、声音与专属互动

## 本地运行

项目需要 Node.js 与 pnpm。

```bash
cd frontend
pnpm install
pnpm run dev
```

检查并构建：

```bash
pnpm run typecheck
pnpm run build
```

## 项目结构

```text
frontend/                       Vue 3 前端项目
要求/                           大赛通知、参赛须知与说明文档模板
前端框架填充说明.md              页面、数据和素材填充指南
长征失物招领处参赛设计与开发计划.md  完整设计方案与开发计划
```

## 内容原则

作品将“已确认事实”“合理推测”“仍然未知”明确区分。虚构复合物件不会被描述成真实馆藏，所有正式历史内容与素材将在补充时注明来源。

## 技术栈

Vue 3、TypeScript、Vite、Vue Router、Pinia、SCSS、Howler.js。
