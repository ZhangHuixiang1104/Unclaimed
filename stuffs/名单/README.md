游戏名单、后随二人、记号与回执悬念均为虚构；真实七人的姓名和经历只可能在**独立、注明来源的史实页**出现，不是游戏人物的真实身份。「转三」不贯穿其他四件物品，饭碗也不提供本章回执。调查顺序为名单 → 行军图 → 电池盒 → 草鞋 → 饭碗，不等于历史时间线。

制作时先核对三份文字是否一致，再推进素材和前端。正式发布前仍需馆方名称及图录核验、逐句史实校对、图片授权和 PC 端试玩。

图片目录中 `06-阿坝日报一碗子报道版面.jpg` 是早期收集的**跨章候选资料**，与名单史实页无直接关系；暂为保留原始研究文件而未删除，不得作为名单素材上屏。
