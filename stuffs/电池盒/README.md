> 第三件物品的专属剧情、图层与史实四站已接入前端；本目录的先后顺序是阅读入口，不是1934—1936年的真实行军时间线。全作解锁与虚构／史实边界以[当前分章设计与运行口径](../../docs/08当前分章设计与运行口径.md)为准。

## 一句话讲清本章

一只**原创虚构的便携供电盒**被反复绑好：内层旧布已磨薄，接线端有清理痕迹，外层新布像是为了继续携行。盒盖内的短笺写着“接点已擦，到了干处再试”，记录栏却没有“已通”或“已发”。玩家能读出有人在潮湿、移动的途中尽力保留下一次试用的机会，却不能凭这些痕迹指认使用者、确认电报发出或填完结果。

史实展柜讲的是**真实的红军通信保障与谢宝金守护手摇发电机的经历**；游戏电池盒不是那台68公斤的发电机，也不是“半部电台”的原件、配件或谢宝金个人遗物。这里的呼应是“器材为何值得修、值得带着走”，不是人物或器物的一一对应。

## 与前两章相同的规则，不相同的玩法

解锁顺序仍为**名单 → 行军图 → 电池盒 → 草鞋 → 饭碗**。名单是拼合、清泥、翻面读三幕；行军图是展开、叠线、描图与等信；本章是**看布层、转动盒体、察接点、打开盖内短笺，再保留一处没有写完的结果栏**。不要复制拼纸、四线追踪、数字热点或长篇卡片墙。

本章不续写名单的“转三”，不解释行军图的无名河谷，也不把裁下的布条导向草鞋。第四章可在档案室按顺序出现，但不是这只盒子的“下一张回执”。游戏完成后以单独按钮进入 `/history/battery`；史实四站读毕才归档并开放草鞋。前端已实现这个流程；PC 实机的图层对位、字号和跨设备存档仍需人工试玩验收。

## 当前必须记住的三个边界

1. “电池盒”是虚构道具；真实史料的核心文物是**手摇发电机**，两者尺寸、功能、馆藏身份不能混称。
2. “擦接点、裹布、留纸笺”是原创情节。真实通信器材的维护、携行与人员守护只能为主题提供背景，不能反证游戏某笔字真的存在。
3. 中国国防报2026年报道谈的是**中革军委发报所用机器**；中国军网通信史文章谈中央红军**多部电台**。统计范围不同，不得合并成“全红军只剩一台电台”。到达陕北、到延安的叙述也不得给未经核实的同一精确日期。
