# 第三件「电池盒」：把下一次试用带到前面

> **专属章节已接入前端；本稿保留剧情与史实边界。** 玩家看到的盒、短笺、笔迹、未填写栏和无名携行者全部是原创虚构；真实手摇发电机、蔡威维修旧电瓶、通信材料厂与谢宝金经历只在独立史实展柜出现。以[现行分章口径](../../docs/08当前分章设计与运行口径.md)为上位规则；同目录《游戏剧情.md》是研究包，旧版“转三／领出联／补草鞋”不进入本章。

## 1. 本章的戏剧问题

玩家在第二章学会了：图上画出的路，并不等于人已经过河。第三章把尺度缩小到掌心附近：**盒子被修了又修，究竟证明了什么？** 它不像地图有远方，只有一段磨薄的旧布、一圈后加的护带、两处光泽不同的接线端，和一张未写完的短笺。

故事核心不是“让电台成功发报”的接线小游戏，而是一次**留给后来继续处理的维护**。短笺记下盒子受潮、接点不稳；擦净后，盒子没有被丢下。磨薄的旧带留在内侧，一层干布隔开盒身，外面又被重新扎牢。盒盖内写：“接点已擦，到了干处再试。”旁边的“试用结果”栏是空的。玩家可以确认有人试图让器材继续可用，却不能由几层布推定几个人，更不能替那一栏写“已通”。

情绪顺序：以为盒子只是破旧 → 发现每层布都为下一次携行或试用留余地 → 看见没有填完的结果栏 → 明白这不是一段可以靠点击补全的胜利消息。**这件道具的主人未知，携行的人数未知，最终是否发报未知。** 不用牺牲、失联、死亡等未经纸面支持的结局刺激情绪。

## 2. 虚构道具的物理因果，先锁死再生图

道具是虚构队伍中的**便携供电盒外壳／携行盒**，不是现实发电机。盒体深灰绿、木胎包薄金属角；两只接线端位于右上，旧布带由背面绕过盒底，后加干布在接点附近形成隔潮衬片，最外层宽护带压住旧带但不把它拆除。盖可向上掀开，内侧贴一张普通纸笺。所有修补只表现**外观与使用痕迹**，不在画面伪造电芯型号、真实军用铭牌、军委番号或可验证的技术接线图。

| 可见物 | 精确可读信息 | 只能推到哪一步 |
| --- | --- | --- |
| 内层窄旧带 | 扁平磨痕、几处旧线脚，部分被新带覆盖 | 至少一次较早的固定或维修；**三层布不等于恰好修三次**。 |
| 中间干布衬片 | 从接线端下方延伸到盒背，边缘有整齐新折 | 有人试图把潮湿的盒身与外带隔开；材料用途由形状支持，但没有当年标准工法证明。 |
| 外层宽护带 | 压住旧结，受力线与旧带不同，末端仍完整 | 后来为了继续携带而重新扎牢；**不能据此推定换了一个人**。 |
| 接线端 | 一端有暗绿旧蚀，一端周围出现更亮的细擦痕 | 曾被清理／处理；亮痕不等于实际通电或收到回电。 |
| 盒盖内短笺 | `潮后接点不稳。`／`接点已擦，到了干处再试。`／`试用结果：＿＿` | 第一行记问题，第二行记处理与后续打算；结果仍空，不是隐藏答案。 |
| 盒底零散短划 | 三四道不规则旧划，**无可辨编号** | 使用痕迹，不用“数字刻痕＝军队编号／人名”编故事。 |

短笺两句是**游戏原创文字**，不仿制馆藏公文、日期、公章和真实人物笔迹。第二句是否由同一人写下不作结论；笔势只做自然深浅变化，不设计“发现第二位书写者”的伪证据。关键区可以放大，清晰文字始终由人工校对的网页字／SVG提供；纸材位图不烘焙 AI 汉字。

## 3. 一次完整游玩，约8—10分钟

| 阶段 | 玩家主动动作与反馈 | 弹出的故事片段 | 不提前给的答案 |
| --- | --- | --- | --- |
| 接收 | 盒子斜放于深色检查台，默认正面；一句问题“为什么旧带没有被剪掉？” | 只见破旧与后来扎的宽带 | 不显示热点数字、角色身份或史实发电机图。 |
| 看布层 | 拖动侧光观察旧线脚；按住外层带头，轻轻掀起约20°，不拆散实物 | 《旧带还在》：新带压着旧结，旧的没有丢 | 不能把每层布当成一位使用者。 |
| 转向接点 | 拖动盒体到右侧45°，放大接线端，对比暗蚀与亮痕 | 《擦过的地方》：这只盒子曾因潮湿被处理 | 擦痕不意味着电报发出。 |
| 掀盖读笺 | 点击盖边铰链／用键盘“打开盒盖”；逐行读短笺 | 《到了干处再试》：有人把问题和下一步写给后来者 | “再试”是未来打算，不等于已经试成功。 |
| 看空栏 | 玩家把视线移到“试用结果：＿＿”；可放大、侧光，但没有刮出隐藏字 | 《没有写下的回音》：故事停在准备重试处 | 不补姓名、不补电文、不补“已通”。 |
| 整理 | 在桌边三句展签中选可被物件支持的一句；随时可改 | 玩家自己说出“有人维护并继续携带；试用结果未知” | 错选只提示回看证据，不扣分或重置。 |
| 进入史实 | 保存**虚构故事**后，独立按钮“翻阅真实档案”才出现 | `/history/battery` 开头明确换幕 | 真实发电机不被称为游戏盒子的谜底。 |
| 建档 | 四站真实资料读完，单独“建立本章档案” | 返回 `/archive`，开放草鞋 | 草鞋不接这只盒子的布条或短笺。 |

四张故事卡允许玩家先发现接点再发现旧带；侧边手账按“旧带→接点→短笺→空栏”整理。首次发现只展示**一段故事**，下拉可看“看到了什么／还不能证明什么”，不要四张同尺寸卡片平铺成仪表盘。状态不因为使用了侧光或放大才硬解锁，工具是阅读帮助，不是仪式性操作。

## 4. 可直接给玩家看的短文案

| 场合 | 玩家文案 | 证据边界（可折叠） |
| --- | --- | --- |
| 首屏 | `一只用布重新扎牢的盒子。旧带还留在里面。为什么？` | 物件是原创虚构，尚未读出结论。 |
| 故事卡1《旧带还在》 | `宽带压着一个已经磨扁的旧结。有人本可以把旧带剪走，却把它垫在了里面，让新的绑扎有处着力。` | 两层可见，具体修补次数、修补者人数不可知。 |
| 故事卡2《擦过的地方》 | `接线端一侧还有受潮后的暗色，另一侧却亮了一小圈。这里被重新处理过；物件没有告诉我们处理之后有没有电。` | 形貌能支持“处理痕迹”，不能单独证明通电。 |
| 故事卡3《到了干处再试》 | `盖内的纸写着：“潮后接点不稳。接点已擦，到了干处再试。”它像一段留给下一位打开盒子的提醒。` | “下一位”是合理阅读，不是可指认的真实人物。 |
| 故事卡4《没有写下的回音》 | `“试用结果”后面空着。盒子被带走前，有人把能做的先做了；剩下的，纸没有替他们作答。` | 空栏不等于失败、牺牲、没有人使用，也不等于成功。 |
| 虚构故事收束 | `有人留下了继续试用的可能。至于那一次是否接通，盒内没有记录。` | 只收束游戏，不插入谢宝金姓名。 |
| 史实换幕 | `以下为真实历史材料。刚才的电池盒与纸笺是原创故事；这里的手摇发电机和通信工作有独立来源。` | 不能把主题相似写成同一物件。 |

### 三句展签，唯一可确认的是范围而非谜底

1. **可确认**：`旧带被后加护带压住，接线端有处理痕迹；纸笺安排到干处再试，结果未填写。`
2. **仅可推测**：`这件东西可能被不同的人接续携行。`——可以讨论，但不能作最终确定展签。
3. **不受支持**：`盒子后来成功供电，并让一份电报发了出去。`——纸面没有记录这一步。

提示只在玩家请求时出现：第一层提示位置（“看看宽带下面还压着什么”）；第二层提示对照（“把‘再试’与结果栏放在一起读”）。不显示正确项闪光、计时器或红叉。结尾不能让玩家输入姓名、发报内容、年份等系统无法核实的信息。

## 5. 史实如何自然接上，而不是伪装成谜题答案

史实四站各回答一个比游戏更大的问题，并按**通信体系→维护→携行→记忆**排列，不声称是某一台电池盒的履历：

| 站 | 读到的真实问题 | 建议主画面 | 与游戏的关系 |
| --- | --- | --- | --- |
| H01「电波从哪里来」 | 红军如何建立无线电队、为何供电和收发设备需要配合？ | 自绘“人／能源／设备／通信”关系图 | 对应盒上的“接点”，不是历史电路复原。 |
| H02「修好，再使用」 | 通信材料厂的零件维修与蔡威利用废铅修旧电瓶说明什么？ | 原创剖面式材料图；注明蔡威属于红四方面军背景 | 对应旧带和擦痕的维护主题，**不能说他修过游戏盒**。 |
| H03「谁把机器带着走」 | 谢宝金与战友守护68公斤手摇发电机的报道怎样讲携行？ | 原创重量／肩带／行程尺度图，避开伪历史照 | 对应“继续带着走”，器物类型不同。 |
| H04「后来谁还记得它」 | 1976年军博重逢的采访、今日军博馆藏怎样留下记忆？ | 原创展柜轮廓＋来源材料卡 | 史实有后来的公开记录；游戏盒的空栏仍然空着。 |

每站先一句最有力的事实，再最多约90字核心叙述；展开层解释出处、人物和口径，末端放可点原报道。H03、H04不靠重复大字口号堆情绪。实际史实文字与图版权利见[史实展柜与核权清单](电池盒章节-史实展柜与核权清单.md)。

## 6. 页面、存档与联调目标

`/archive`（行军图归档后电池盒解锁）→ `/object/battery`（四张故事卡、展签、保存虚构故事）→ `/history/battery`（独立史实四站）→ 返回档案室（建档成功，草鞋解锁）。已归档可从路线档案重读史实，未完成的历史节点仍封存。专属页面已接入；仍待PC浏览器实机验收图层对位和交互手感。

当前稳定故事线索ID为`battery-old-band`、`battery-terminal`、`battery-note`、`battery-blank`；史实阅读事件为`battery-history-01`—`04`。转动视角、侧光和放大为UI状态，不进云端；故事片段已读、展签已核、史实站已读和归档标志会随账号进度保存。旧占位版`battery-cut/first/slip`进度不会被静默当作新版通关：旧记录保存在`legacyBatteryRecord`，只重开本章，不影响名单、行军图。网络断开时写“本机待同步”，不能冒称“云端已保存”。

### 验收

1. 不看策划文档的玩家能复述“受潮→处理→带着等下一次试”的三步，并主动指出结果未知。
2. 不能在发现两条痕迹后就出现史实按钮；必须四张故事卡和展签核对完成，再由玩家主动进入。
3. 不靠数字热点也能通过鼠标、键盘、125%缩放找到全部痕迹；缩小后盒内文字仍清楚。
4. 刷新、退出重登、断网重连均保留已经确认的进度，未保存的操作有明确提示。
5. 游戏页没有“转三”、草鞋补料、王诤和谢宝金姓名；史实页没有把虚构道具写成真实发电机。
