# 「电池盒」PC 制作稿：布层、接点与空栏

> **本稿保留原始设计坐标；现行实现以`frontend/src/components/investigation/BatteryInvestigation.vue`为准。** 以[情节方案](电池盒章节-情节与史实撰写方案.md)的虚构盒与短笺为唯一游戏纸面文本来源。P01—P08和三张独立字形SVG已接入；下方坐标是早期草图，不代表组件当前的CSS百分比命中区。PC实机缩放与点击准确度还需人工复核。此稿不规定任何真实文物的尺寸或线路。

## 1. 画面空间与视觉层级

基准视口1920×1080，验收1440×900和浏览器125%缩放；暂不为手机端另起版。沿用全作深绿黑工作台、暖纸与低饱和朱红，但本章主物体是**深灰绿盒＋暖米色棉布＋微弱旧铜**，不再复制名单的大片纸面或行军图的河谷。容器最大宽约1740px：左侧检查区约62%，右侧“工作记录”约38%。右侧默认只显示当前故事片段与一行边界，不堆四张同时高亮的卡片；底部工具条不制造空白黑区。

章节标题约32—38px，故事卡题22—24px，主要阅读字16—18px／行高1.65—1.75，按钮16px，元信息14px以上；纸内短笺的实际显示字不低于16px，必要时在侧栏同步转录。`--font-display`用于章名与卡题，`--font-sans`用于交互与正文，`--font-mono`只用于内部编号。污渍、纸纹、玻璃光层**不得盖在文字上方**；与前两章共享颜色变量而不另造一套字体。

## 2. 统一坐标：盒子画在 `1600×1000` 透明舞台里

## 4. 互动反馈及防误读

1. **掀带**：鼠标按住带头上拉，带头转动、阴影变化，露出旧线脚；不做“抽断布条”的惩罚动画。键盘按钮为“掀起外层护带／放回护带”。
2. **侧光**：光扫过材质时只提高旧线脚和擦痕的局部反差，不在其上画红圈。关闭侧光仍可放大阅读。
3. **转盒**：拖动或键盘“看右侧／看正面”，最多左右45°，不无限旋转导致看不见操作区；底部显示当前视角的文字提示。
4. **接点观察**：放大后出现暗蚀／亮痕的并排细节；仅反馈“曾处理”，不播放真实摩尔斯电文或“电波已接通”的成功音。
5. **开盖**：触发清楚的盖缝动作与纸笺位置；短笺可独立放大，文字为屏幕可选、可朗读的网页文本。
6. **空栏**：鼠标停留只给轻微纸纹变化；第一次点击出故事卡《没有写下的回音》。再点击只可重读，绝不让玩家“填入”官方结果。

玩家若确实找不到纸面细节，可以主动打开“观察位置”列表，列表只写“布带边缘／接线端／盖边／纸笺下端”，不泄露相应结论。所有操作给鼠标与键盘等价入口。界面声音可关，声音不能承担唯一线索。
