# 电池盒章节独立史实视觉：H01—H04

本目录已有四张**团队后制的原创SVG示意图**。它们不是1930年代照片、馆藏原件复原或已获授权的真实资料图片。真实资料图片仍只在`../史实材料/images/`作内部研究，不能因为存入项目就用在正式构建。史实事实及图片逐件状态见[展柜与核权清单](../电池盒章节-史实展柜与核权清单.md)。

| ID／建议文件 | 内容与制作约束 | 画面重点 |
| --- | --- | --- |
| H01 `history-communication-chain.svg` | 抽象表示“人协作—能源—收发设备—信息”，不画一条号称适用于所有1930年代电台的准确电路；标“通信保障关系示意”。 | **一条电波背后有多人**，不用真实设备照片。 |
| H02 `history-repair-material.svg` | 三栏“旧零件／维修／继续使用”；蔡威旧电瓶铅板作为**另一个部队的可核事例**放材料卡，不绘制其亲手维修的假现场。 | **修理让稀缺器材多一次可用机会**。 |
| H03 `history-generator-carry.svg` | 用68公斤文字标注**手摇发电机重量**，旁边用无人物五官的轮廓展示抬、背、拖三种报道提及的携行方式；不是文物外形复原。 | **重的是机器，也是人的坚持**；不过度煽情。 |
| H04 `history-museum-memory.svg` | 展柜轮廓与报道／采访卡，标“现代报道与今日馆藏”；留一个未来可替换为授权照片的版位。 | **有人在多年后认出了老战友**；不生成1976年合影。 |

四张使用与项目同系的中文字体回退栈及现有配色：暖纸、深绿黑、低饱和朱红，仅H01/H02少量旧铜线条；每张只容纳一句核心事实、一个图示和一条材料标签，避免满屏说明。独立SVG不能自动继承页面CSS变量，接入时需核对项目实际字体。史实页的长说明用HTML文字，SVG文字也需人工逐字核源。所有图注写“据公开报道编绘／示意”，不能写“1935年原图”“军博原件复原”。获取授权真图后逐件替换，不绕过核权流程。

当前状态：四张SVG已通过XML格式校验，并接入`frontend/src/components/history/BatteryHistoryExhibit.vue`。文字按本章[史实展柜与核权清单](../电池盒章节-史实展柜与核权清单.md)控制口径撰写；仍待PC页面渲染和上线编辑复核。尤其H02的蔡威事例来自不同部队，H03的68公斤属于手摇发电机，H04不能冒充重逢现场图。
