# 「电池盒」史实展柜与资料核权清单

> **内部事实与发表闸门，2026-10-21。** 本文根据本目录《游戏剧情.md》研究摘录、17张本地参考图及文末已核查的公开报道重编。游戏盒与其短笺为虚构；本页说到的真实文物是**手摇发电机**，不能把两者合并。图像存于本地、新闻页面能打开或写有“来源”都不等于拥有转载、裁切、改编和公开网页展示权。

## 1. 玩家史实页的叙事线：通信靠一群人维护

`/history/battery` 应在游戏故事保存后由“翻阅真实档案”主动进入，页面开头明确写“刚才的电池盒是虚构故事；以下材料记录真实的通信保障”。四站按**建立联系 → 修好设备 → 背着设备走 → 文物被后来的人记住**展开。它们来自不同人物、部队与年份，不拼成一件盒子的连续履历。

| 站 | 玩家先读的事实短句（草稿） | 展开阅读的依据与尺度 | 材料类型／边界 |
| --- | --- | --- | --- |
| H01「让电波有去处」 | `无线电不是一只会说话的箱子。报务员、收发设备、能源和修理者，都在同一条通信链上。` | 中国军网梳理红军无线电队、长征前多部电台与修理装配能力；具体电源配置因设备与时期而异，不画成“每台发报机必经同一电池盒”。 | 现代通信史文章。不能用它证明游戏盒的型号，也不能把“半部电台”误称半个可用发报机。 |
| H02「坏了，还能修」 | `器材少，维修就不只是技术工作：能再用的零件，往往得反复用。` | 中国军网引王诤回忆：电台运输队200余人、器材零件100多担，到陕北只剩1担；人民网记红四方面军蔡威利用废铅重做旧电瓶铅板。两则讲**不同范围**的维修与消耗。 | 回忆录转述／人物事迹报道。不能从“100多担→1担”推算战损、死亡或具体去向；不能说蔡威修过谢宝金的发电机。 |
| H03「68公斤，怎样带过去」 | `一台手摇发电机重68公斤。公开报道记下，谢宝金和战友一路守护它，雪山要扛，草地要拖。` | 《中国国防报》2026年报道及央视2016年谢林贵口述都记谢宝金与发电机；“128人加强连后来只剩3人”属于报道口径，宜写“据报道”，不把其余人一律写成阵亡。 | 当代报道／家属口述。图片中的是真实发电机，不是游戏盒；关于到达延安／陕北的叙述不要自行配精确同一天日期。 |
| H04「老战友在展柜里」 | `多年后，谢宝金在军事博物馆再次见到这台机器。故事没有停在通信完成的一刻，还留在守护它的人记忆里。` | 中国纪检监察报2019年文章与央视2016年采访均记载军博重逢，动作、引语版本不同。军博馆藏与“国家一级文物”见2026年国防报报道；展签正式名称、编号仍待馆方核。 | 后来采访／馆藏报道。1976年的重逢不能被写成1930年代现场照片，也不能拿文物擦痕推定虚构短笺的作者。 |

各站主文建议60—100字，展开层约150字，材料图只保留一幅强视觉加最多一处可切换的佐证。不要让H03和H04都用同一张发电机照片、大数字和满屏口号；焦点从“器材”自然移到“守护的人”。末尾不是“电池盒的主人就是谢宝金”，而是：“真实的发电机留下姓名和馆藏；游戏盒的结果栏仍然空白。”

## 2. 关键数值与混称风险

| 问题 | 查到的公开口径 | 本章处理 |
| --- | --- | --- |
| “只有一台”还是“有14部”？ | 《中国国防报》2026年报道说**当时中革军委发报所用的一台发报机和一台发电机**；中国军网《红军的第一部电台》讲**中央红军长征时携带14部电台**。对象、时点与统计范围不同，报道之间也仍需档案细核。 | 不写“全红军只有一部电台”；若引用“一台”，原句旁必须保留“据该报道／中革军委这一设备”的限定。展柜主文可避开争议数值。 |
| 68公斤是什么的重量？ | 国防报、央视、纪检监察报均用于**手摇发电机**。 | 不写成电池盒、电瓶或整套电台重68公斤。游戏盒不设真实重量。 |
| 128人到3人说明什么？ | 多篇报道转述一个加强连保护核心设备，后期仅剩谢宝金等3人。 | 写“据报道，承担护卫的加强连后来只剩三人”；不据此推定每一位其余成员的具体命运。 |
| 100多担到1担说明什么？ | 中国军网引王诤回忆说电台运输队器材零件在长征过程中大幅减少。 | 不等同“100多担电池全部耗尽”“人从200余只剩一人”；剩余物料的分类和去向另核。 |
| 蔡威的旧电瓶能说明什么？ | 人民网、中国军网记载他利用废铅重做铅板，是**红四方面军**通信保障事迹。 | 可说明当时有修旧电瓶的实践；不放进中央红军谢宝金个人时间轴，更不指认为游戏盒的原型。 |
| 1976年军博重逢的话 | 纪检监察报2019、央视2016等对哭、伸手、引语细节不完全一致。 | 主文只说“据家属采访，曾在军博重见发电机”；长引语需选定原报道、逐字短引并附来源，不混编多个版本。 |
| 延安和陕北 | 一些报道写“背到延安”，通信史材料写“到陕北”；有关庆祝大会的时间与地点需要更直接证据。 | 不把到陕北时间硬标为“1935年10月已到延安”。非必要不写庆祝大会精确人数。 |

**默认发布策略**：不把 `史实材料/images/` 复制到 `frontend/public`、不在生产构建中 import、不通过运行时“隐藏地址”公开。内部开发预览若后续接研究图，必须像前两章一样采用开发环境白名单、清楚标内部核对，且生产构建自动回退到原创史实视觉。获得授权后再逐件评估，不做一次性“把整目录上传”。

## 4. 可先使用的独立史实视觉

无媒体图授权时仍可有漂亮、完整的史实页：H01原创通信协作关系图、H02原创“材料—修理—再用”信息图、H03原创重量与携行方式示意、H04原创展柜轮廓＋馆藏报道来源卡。均明确标“据公开报道编绘／示意”，不生成假文物照片、假1930年代报纸、假馆藏编号或谢宝金AI肖像。制作清单见[史实视觉/README.md](史实视觉/README.md)。

## 6. 待办与发表闸门

- 向中国人民革命军事博物馆核手摇发电机正式藏品名、馆藏编号、展陈原件/复制件属性、授权图版与引用方式；向湘江纪念馆核08图展品属性。
- 为拟公开的每张图记录`原始URL、摄影者／制作者、持权方、图中再包含的展品与作品、许可范围、署名、期限、核验人`。没有明确许可就仅提供原页链接。
- 核国防报2026报道“中革军委只有一台”与中国军网通信史数量口径的统计对象，不用一张大数字海报放大争议。
- 如史实页写“国家一级文物”“128人到3人”“1976年重逢”，逐句挂S1—S3，区分报道、家属回忆与馆方正式档案。
- 检查游戏页和史实页全文：无“转三”、无跨章补草鞋、无“这只电池盒是谢宝金背的”、无伪当年照片；玩家版不出现本清单的授权待办。
