## 本轮实际图像生成指令摘要

1. **俯视碗**：一只素色灰米粗瓷旧饭碗、正上方、右上沿一处稳定修补、真正透明背景；禁止红花、姓名、军徽与馆藏铭牌。
2. **斜视碗**：以上张为编辑参照，仅改变视角约 35°，锁定釉面、轮廓与右上修补。
3. **底面碗**：以俯视与斜视为参照翻底，保留同碗特征，仅设两道无字义的细痕，不暗示时间先后。
4. **包纸正面**：一张素色米黄旧纸，四角折痕和浅碗压印，平展俯视、无字、透明。
5. **包纸反面**：以上张为编辑参照自然翻转，保留折痕与外形，中部留给后加短句。
6. **沿口局部**：从已验收碗俯视图放大同一修补，不新增缺口。
7. **底面局部**：从已验收碗底图放大同两道痕迹，不生成字母、数字或第三个记号。

完整可复用生产提示词与拒收条件见[资产清单](../饭碗章节-美术资产清单与逐张制作提示词.md)。本轮 PNG 已检查为 RGBA 且四角透明；**尚未进行前端真实浏览器装配与尺寸适配验收**。如果斜视切换或局部放大显得突变，应优先通过前端渐变/同图放大处理，必要时重新生成对应视图，不修改剧情来迁就错图。
