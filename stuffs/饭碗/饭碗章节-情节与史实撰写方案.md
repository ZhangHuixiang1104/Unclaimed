# 第五章《留给后来的人》：情节与史实撰写方案

> 状态：第五章专属四幕故事与四站史实已接入；本文件保留剧情、事实边界与后续视觉验收依据。承接前四章“先看游戏物件、再读独立史实”的顺序，不继承其具体谜题。

## 一句话、章节主问题与情绪走向

档案袋里是一只被修过的旧碗和一张素色包纸。最先引人注意的是碗底两道像记号的痕迹，但真正能读出的不是两个姓名，而是包纸上那句“**洗净放回灶边，后来的人还用得上。**”

玩家任务：亲手把碗从包纸中取出、观察它如何被留用，再写一条不替未知者署名的展签。

主问题：**这只碗能告诉我们谁吃过饭吗？如果不能，它仍然留下了什么？**

情绪线：把“两个刻痕＝两个人”的直觉放慢 → 发现物件曾被修好、继续使用 → 读到一份朴素的留用嘱咐 → 接受人名未知，却有人把吃饭这件事留给后来者。第五章收束整部作品，落在保存与克制，不用“前四件原来同属一人”的总反转。

## 证据边界先行

1. 游戏旧碗、包纸、笔迹、修补、两道痕迹和所有互动文字都是**原创虚构**。不设计成仁化真实“红军碗”的复制品：游戏碗素色、可见旧修补；真实报道中的碗为带淡红花纹的瓷碗。
2. 碗上的使用痕迹能说明它有使用与修补经历；两道痕迹的形成原因和先后顺序不明。不能仅凭图层推断准确修补次数、使用年限、两名主人、两次交接、长征具体地点。
3. 包纸句子是游戏世界里的一条文字证据，能支持“写字者希望此碗被洗净、再给后来的人使用”。它不能证明这句话被执行了，也不能证明是谁写、谁吃、何时写、是否有伤员。
4. “后来的人”是本章的开放称呼，不与名单的“后随二人”、电池盒、行军图、草鞋或仁化真实徐排长绑定。

## 开场与视觉叙事

档案袋内先露出一只布纹包纸，中央被旧碗压住；没有红绸、军徽、姓名和“文物原件”章。页面只给一行可见任务：“先看看这只碗为什么一直没有被丢下。”碗的阴影与包纸折痕让物件有重量。背景保持本作深绿夜间工作台，暖纸只用于包纸和故事页；并非满屏解说牌。

游戏时长目标 5—8 分钟。玩家可自由回看，但四段故事按动作自然展开，不靠预先编号的热点、空白倒计时或密集解题卡。

卡片正面每次只突出一句，展开才读 2—3 句。发现卡直接进入右侧“碗边手账”，不弹第二层成就面板。所有动作可重试，已发现的故事不回退。碗底痕迹初始不画圆、不标 1/2，只有玩家翻到恰当角度并开侧光才由画面和轻微音效提示；无声模式以细线高光与短字幕替代。

### 需要明确的交互反馈

- 点击无效区域只提示“试着转动碗 / 翻包纸”，不说出线索位置。
- 侧光只是看清已有痕迹，不进行“真实拓印”或模拟刮擦文物；不要求玩家反复乱点。
- 第 03 幕不做“修补压住刻痕”的先后谜题；画面只需诚实表现两处不同走向的痕迹。
- 第 04 幕文字优先 HTML/SVG 可选中正文；手写字图只作为气氛，绝不让读字成为谜题。

## 故事整理：不是猜谜，仍要作判断

四段全部见到后，左侧碗保持可转动，右侧出现三张**展签候选**。玩家选择一张并看依据反馈；错误选择可立即重选，不扣进度。

1. 正确：**“旧碗留有使用、修补与两道痕迹；包纸嘱咐将它洗净留给后来的人。用碗者是谁、嘱咐是否实现，仍无记录。”**
2. 误读甲：“两道刻痕说明两名红军先后用过这只碗。”反馈：“痕迹没有姓名，也不能证实使用者身份或人数。”
3. 误读乙：“包纸证明这只碗最终被交还给写字的人。”反馈：“纸上是给后来者使用的嘱咐，不是已经完成的交还记录。”

保存正确展签后，游戏故事收束为：

> “碗破过，也被接住过。它没有把端起它的人一一记下；包纸只留了一句话：洗净放回，后来的人还用得上。我们不替它写姓名，也不替那句话写一个已经发生的结局。**一只碗能留下的，不止是谁用过，还有谁曾想到下一顿饭。**”

随后**单独出现**“翻阅真实档案”按钮。史实内容此前不得在碗上、故事卡和选择题里露出。按钮进入 `/history/bowl`，而非 `/history` 目录页，更不能外链打开就把玩家弹走。
