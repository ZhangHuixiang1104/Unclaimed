# 《留给后来的人》前端制作坐标与 SVG 方案

> 第五章专属检查台与独立史实展柜已按此稿接入。以下坐标仍是 PC 视觉验收参考，需按真实浏览器截图微调；不得将百分比坐标写死为图片像素。前四章故事不因此改动。

## 页面骨架与视觉权重

设计基准：1920×900，内容最大宽约 1640；检查台工作区建议 1440×760。沿用全站深绿/近黑背景、暖米色纸、暗红主按钮，遵循 [前端视觉规范](../../frontend/DESIGN_SYSTEM.md)。左侧约 62% 为可操作的碗与包纸，右侧约 38% 为**一块**窄手账面板；不再用五张等权小卡把检查台填满。

首屏应能同时看到“碗”“本次问题”“当前唯一动作”。章标题 40—48 px 宋体展示字，问题 18 px 加粗无衬线，正文 16 px、行高 1.7 左右，故事卡标题 26—28 px，按钮 14—16 px。低对比或 12 px 宋体不可承载线索和历史事实。纸张本身可有纹理，但 DOM 正文必须高对比、无透明度削弱。

```
┌──────────── 章节标题 / 游戏物件 · 原创虚构 ─────────────┐
│ 一只被包住的碗，为什么还留在这里？                    │
├────────────────────────────┬─────────────────────────┤
│                            │ 碗边手账                 │
│   素包纸 + 可托起的旧碗      │ 当前发现（最多四段）     │
│   操作时才出现光带/局部      │ 只展开当前段，其余一行   │
│                            │                         │
│   展开纸 / 转动碗 / 侧光     │ 观察边界 + 下一步        │
├────────────────────────────┴─────────────────────────┤
│ 已读四幕后：一条展签选择区 → 保存故事 → 翻阅真实档案  │
└──────────────────────────────────────────────────────┘
```

不使用悬空大片空白补“高级感”：碗展示区域在 1920×900 下至少占左栏高度 55%；右栏随故事自然增长，但最大高度不得把主操作推到首屏以下。滚动时导航不压住纸句；弹出故事卡后背景冻结，关闭返回原操作位置。

## 统一坐标与图层

舞台坐标 `(x,y)` 为左侧可操作工作台的百分比，原点左上。图片 `object-fit: contain`，热点须随物件 SVG 包围盒缩放，不用固定屏幕坐标硬叠。

| 图层 / 状态 | 建议范围或中心 | 可见性与作用 |
|---|---|---|
| 包纸正面 | 中心 (49,54)，宽 80%，高 74% | 初始可见；折角可拖，短句绝不在正面透出。 |
| 碗正面 | 中心 (50,52)，直径约 45% 舞台宽 | 初始压在包纸上；可托起 6—8% 舞台高。 |
| 旧磕与补处 | 碗母版相对坐标约 (74,31)，实际以验收图修正 | 不常显；旋转约 50° 后进入可点观察区，focus/hover 给细线。 |
| 底部双痕 | 底面图相对中心 (48,58)，热点不是两颗独立圆点 | 托起翻底且启动斜光后可读，光带滑动显形。 |
| 包纸反面文字 | 包纸相对框 `(16,38)—(82,62)` | 第 04 幕才翻转显示；文字 HTML/SVG 叠加，不烘进位图。 |
| 手账 | 页面右侧 38% | 初始只示本次问题与操作提示；读到一幕增加一条，不预填结论。 |

页面初始无 `1/2/3` 热点、发光目标圈和可推断未来事实的锁图。hover/focus 只提示“可转动”“可翻面”；移动鼠标不直接弹结论。键盘版提供对应的明确动作按钮，无需模拟拖拽精度。

## 状态机：必要条件与反剧透

`包裹中 → 已展开包纸 → 已看碗沿 → 已翻底并用侧光 → 已读包纸背面 → 四段手账齐备 → 选择展签 → 保存成功 → 单独开启史实`。

- **01 展开**：拖折角或按“展开包纸”按钮，动画 350—500 ms，马上给故事卡 01。允许再次合上/展开，不清掉已读卡。
- **02 看沿**：转动把手/左右方向键让碗倾转；到可读角度后局部轮廓显示。点击补处弹故事卡 02。角度容差建议 ±15°，不能像像素寻宝。
- **03 看底**：按“托起翻底”，动画不超过 600 ms；触控条或方向键移动斜光。光带扫到两道痕的共同区域时触发故事卡 03；不要求依次点两痕，也不把痕迹预画成两个头像。
- **04 翻纸**：前三段读完才提示“纸还有一面”；点击纸边翻面，DOM 文字即时出现并可选中，触发故事卡 04。不能把“后来的人”解释为名单人物。
- **展签**：四幕均读后才显示，错误选择只反馈所越过的证据边界；保存正确选项后等待云端确认，再显示主按钮“翻阅真实档案”。

调查动作可以任意重看，**读到的故事和保存记录不可因翻回正面而丢失**。发现条件以故事动作完成为准，不按单纯页面停留时间计数。

## SVG 与文案实现

1. `bowl-raking-light.svg`：低透明度柔和斜光，动画只改变角度/遮罩；无强烈扫描仪线、故障闪烁或红色探照效果。
2. `bowl-rotation-guide.svg`：随碗弧线的小箭头和焦点描边。纯装饰用 `aria-hidden`；真实按钮提供 `aria-label="转动饭碗"` 等明确名称。
3. 碗底叠层：两处痕迹由经过美术验收的底面图承载，SVG 遮罩控制可见度；若叠层单独画痕，要与图纹理对齐，不能悬浮如 UI 密码。
4. `bowl-paper-ink.svg`：只显示经过人工逐字核对的短句。旁边/同层有真正的可选中 HTML 文字供辅助阅读；普通文本优先于造型字图。
5. 史实 `history-bowl-01…04.svg`：原创后制示意，不用伪旧边框暗示实拍。图下写清“原创后制示意，非历史照片或馆藏原件”。

故事卡支持 Esc / 关闭按钮；关闭后焦点回触发元素。页面允许 `prefers-reduced-motion`，关闭动画时文字和按钮顺序仍完整。声音关闭不影响发现；斜光靠视觉与文字反馈即可理解。

## 页面跳转、云存档与终章

| 页面 | 进入条件 | 离开条件/目的地 |
|---|---|---|
| `/archive?focus=bowl` | 前四件按现行解锁链归档；老存档按迁移规则处理 | 点击第五件进入 `/object/bowl` |
| `/object/bowl` | 已登录并已解锁 | 四幕、正确展签及服务端保存成功后显示“翻阅真实档案”，进入 `/history/bowl` |
| `/history/bowl` | 同账号故事已保存；已归档者可重读 | 四站每站实际阅读后，服务端确认“建立档案”；进入 `/ending` 或档案室并突出终章入口 |
| `/ending`、`/ticket` | 五件均归档 | 终章写五件之一的展签，不默认饭碗是其他四件的归属答案 |

当前存档使用 `bowl-wrapper-opened`、`bowl-rotated`、`bowl-light-on`、`bowl-base-viewed`、`bowl-paper-turned` 等动作键，四段线索为 `bowl-unwrapped / bowl-rim / bowl-marks / bowl-paper`，史实站为 `bowl-history-01…04`。`bowl-marks` 在新版只表示第三幕底面观察，不继承旧版通用线索语义。内容版本为 `independent-chapters-v6`；旧版未完成饭碗进度备份到 `legacyBowlRecord` 后重开该章，已归档旧档保留终章资格。

## PC 验收场景

1. 1920×900 与 1366×768 实际浏览器检查：不出现大块无用途空白；包纸短句、主按钮、侧栏文字无遮挡、无糊字/截字。
2. 鼠标与键盘两条路径都能读到四幕；斜光容差正常；不靠音频通关。
3. 未翻纸之前页面 DOM 不含可见的末句、史实人物姓名、真实碗照片；锁定 `/history/bowl` 不能直接通过地址提前看。
4. 故事卡关闭后仍在检查台；史实插图放大后在页内关闭；不发生“翻阅真实档案”把玩家弹到站外。
5. 断网保存、服务端恢复、刷新、退出重登均测试；失败时不假报“已保存”，修复连接后可重试并恰好建档一次。
