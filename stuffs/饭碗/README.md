# 第五章《留给后来的人》

本目录是第五章的**制作入口**。游戏物件透明 PNG、辅助 SVG 和四幅史实后制示意已完成首轮制作，前端专属四幕流程与四站独立史实展柜已接入。玩家先读一只原创虚构饭碗和包纸留下的有限信息，再单独翻阅仁化“红军碗”的真实故事。第五章完成后进入全作终章；五件物品按游戏顺序解锁，不因此变成同一人的遗物或同一历史事件的证据。

## 阅读与制作顺序

1. [情节与史实撰写方案](饭碗章节-情节与史实撰写方案.md)：四次动作、故事卡、展签选择、四站史实与终章衔接。
2. [美术资产清单与逐张制作提示词](饭碗章节-美术资产清单与逐张制作提示词.md)：原创饭碗与包纸的分层图、字图、史实后制示意及逐张提示词。
3. [前端制作坐标与 SVG 方案](饭碗前端制作坐标与SVG方案.md)：PC 检查台坐标、隐藏热区、状态机、路由与存档验收。
4. [史实展柜与核权清单](饭碗章节-史实展柜与核权清单.md)：可发布事实、来源差异、研究图片的版权边界与上线前待办。
5. [美术母版](美术母版/README.md)：七张已生成的透明 PNG 与人工 SVG；仍待浏览器装配验收。
6. `史实视觉/`：四幅原创后制 SVG 示意；展示时须附“非历史照片或馆藏原件”图注。
7. `史实材料/images/`：已收集的公开报道图片，仅供内部研究核对；**不等于取得游戏内公开展示授权**。

`游戏过程.md` 为早期研究底稿，其中“转三”“后随二人”“借碗记”“接讫点框”“与名单裁口相接”等跨章节设计已退出当前口径，不得进入新图层、玩家页面或史实图注。本章以本目录四份新方案和已接入的专属前端流程为准。

## 不可混写的两条线

| 游戏故事（原创虚构） | 真实史实（公开报道） |
|---|---|
| 无名旧碗、素色包纸、修补与两道痕迹、包纸上的短句，均为专为本作创作的叙事道具。 | 据公开报道，1934 年红军经过粤北仁化，蒙家财、黄乙秀夫妇照料受伤的徐排长；临别留碗，蒙家后代长期保存，后捐出展陈。 |
| 没有确定的年代、地点、部队、主人和后续去向；碗底痕迹不是两个人的记号。 | 真实碗是带淡红花纹的瓷碗，不是游戏里的素色修补饭碗；两者无器物、人物或流转关系。 |
| 先完成游戏展签，才出现“翻阅真实档案”。 | 史实展柜独立呈现出处与未知，不为游戏中的空白补姓名。 |
