# 「行军图」史实展柜与图片核权清单

> **内部史实与发布校核稿，2026-10-19。** 已逐类查看本目录的30张研究图，并对照文末公开报道。文件名、图片水印、展牌和本地保存时间均不是版权许可，也不能单独证明历史断言。玩家端只呈现已核事实、短文、来源和明确的虚构／史实边界；本清单中的“待授权”“待核图版”等制作话不进入正式故事正文。

## 1. 历史主线与游戏主线必须分屏

玩家在 `/object/map` 看的是**原创无名河谷行路小图**：四层墨线与“等信”结尾皆属虚构。先保存游戏故事，再从独立按钮进入 `/history/map`。史实屏顶部固定说明“以下为真实历史材料；游戏小图不是这批地图、没有对应的真实河谷或渡口”，并给每件材料标“当年文件／现代采访／后制示意／纪念地今景／展陈复原”。不得把游戏线条渐变叠在真实路线图上制造同一物件的错觉。

历史页的时间轴分清**1935年1—3月四渡赤水 → 3月底南渡乌江 → 4月下旬云南曲靖地图消息 → 4月底至5月初金沙江渡口行动**。四渡赤水是四次渡**赤水河**，南渡乌江在其后；金沙江是另一条河、另一阶段。名单章的土城伤员照护虽与同年历史相邻，但行军图并非名单“转三”的续页。页面导航按游戏顺序解锁，不冒充历史事件顺序。

每站正文控制约70—110字；“看材料”展开层约150—220字。页面视觉不是长篇论文：左侧1个强视觉/原创示意、右侧事实短句＋“材料告诉我们／没有告诉我们”，底部直接回链原报道。四站读完才允许建档。历史图如未获授权，主视觉用团队自绘简化图、纯文字材料卡与原文链接，**不把研究图放进正式构建**。

当前页面把史实分三次呈现：顶部用“1—3月四渡赤水 → 4月27日曲靖获地图 → 5月初金沙江摆渡”建立时间主轴；进入每站先读一句核心史实；再点开三个时间／地点片段阅读经过。四站的片段依次为：①一渡赤水／折回黔北／第三、四次渡河，②进入云南前缺图／关下村截获地图／今日三元宫副本，③4月29日速渡指示／龙街渡受阻／洪门渡部分渡江及主力改道，④5月2日夜先遣队寻找船工／5月3日起接续摆渡／船工姓名进入后世纪念展陈。每个片段只挂本馆对应的报道入口，避免把后来的照片、展板或游戏小图当成当年原件。

## 5. 核权与发表闸门

图片与地图要建一张逐件表：`本地文件名 → 原始URL → 原图标题 → 作者/摄影 → 发布机构 → 摄制/发表日期 → 是否含内层作品或人像 → 许可范围（线上展示/改编/裁切/参赛） → 要求署名 → 到期/撤回条件 → 核验人/日期`。目前这30张图均缺完整链条，**默认不得进入正式构建产物**；“引用注明来源”不能自动代替许可。

正式使用前至少办妥：① 向三元宫/馆方核02是否原图、副本还是普通陈列；② 向杉乐纪念馆确认19—20名单归属、正式用字及图版授权；③ 核12、13、17、21、22、25、26、28的具体身份/年代；④ 对09—11、27、29补拍摄时间与权利；⑤ 自绘历史路线图也需复核时间、地名、比例及图例，并标“据资料编绘”；⑥ PC 页面全文做事实审校、视觉校对和来源链接检查。

没有图片授权的可发表降级版本：**四站正文＋来源可点链接＋团队自绘非精确示意＋清楚的材料类型标签**。不做“临时先上图、后面再补授权”。玩家版不显示“权利待核”等幕后语，未核图版直接不出现。
