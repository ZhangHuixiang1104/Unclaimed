# 「行军图」PC 前端制作稿：折纸、四层线与阅读交互

> **制作坐标与已接入实现对照。** 2026-10-19。以[情节方案](行军图章节-情节与史实撰写方案.md)为唯一游戏文本来源；`stuffs/行军图/游戏过程.md` 中“转三”旧稿不得复用。本章是“逐层读一张不断改写的图”，不是名单的拼片／清泥流程，也不是以游戏坐标临摹真实长征路线。

## 1. 先把空间和字号定死

PC 参考视口 **1920×1080**；在1440×900与浏览器125%缩放下仍需完整操作，不为手机端另做设计。页面三段：上方章名与虚构道具角标；中间左侧检查台约 `minmax(700px, 1fr)`、右侧故事手账 `360–420px`；下方工具与展签不让主画面下方出现大块空白。检查台内的纸使用统一 **`viewBox="0 0 1600 1000"`**，纸外形约 `(80,80)` 到 `(1520,920)`；任何热点、文字、笔迹都绑定纸坐标，随等比缩放、放大与平移共同移动。

建议背景 `#111612`，纸 `#ddd0b6`，正文 `#eee6d6`；四线不是四种艳色，分别用灰铅 `#68665d`、淡褐 `#8a7962`、赭红 `#9c5946`、深墨 `#3b3831`。当前项目使用 `--font-display`／`--font-sans`／`--font-mono`，本章继续沿用：标题以 display 32–38px，故事卡标题22–24px，正文16–17px、行高1.7，界面说明14px、行高1.6；12px以下只允许编号或非关键装饰。**纸上的关键汉字在1920宽屏实际显示不低于16px**；史实来源说明不低于13px。低对比的纹理不得经过文字层上方。

## 2. 一张纸，而非四张图：图层结构

| 层（下→上） | 实现／文件建议 | 固定规则 |
| --- | --- | --- |
| 台面 | CSS渐变或原创 `map_desk.webp` | 不在图片里烘焙按钮、真实地图或人物。 |
| 纸张母版 | 无字、无路线的 `map_paper_blank.png`；SVG纸边共用裁切 | 正反面同一外轮廓。旧纸纹理低对比，平视俯拍，不仿某件馆藏。 |
| 地形底纹 | 自绘极简等高线、河道、沟口/西坡/北滩/下滩/高地 | **无真实地名与地理坐标**；河流在右，地形只是虚构视觉。 |
| 四层笔迹 | 四条独立 SVG `<path>`，笔压与重叠按 A→B→C→D 顺序 | 必须可以单独显示／隐藏、做交叠放大和描图；不要由AI生成线。 |
| 折痕与压笔 | SVG阴影/遮罩；背面压痕同位置 | 折痕改变可见区域但不移动纸上文字坐标。 |
| 手写字 | 经人工逐字校对的SVG轮廓或独立透明PNG | AI不得代写汉字。背面文字不镜像，纸材质按翻面方向对位。 |
| 交互叠层 | HTML按钮、SVG透明命中区、侧光径向蒙版、描图尺 | 未发现前无数字热点/呼吸圆；已读处才可给细微书签。 |

美术母版应先用 SVG 灰块搭全流程，等纸面文字和命中区验证后再生图。名单已有的泥点、三片切口与透明手写字**不能直接复制**到这张图。

| 纸背更新记录 | `(185,210)` 起，每行高约110 | 四条简短回报，详见下节。 |

四条路径须与上述点位一致，尤其D的末端在高地，**绝不能自动延伸到河对岸**。以下几何只是线条关系的起稿，后续矢量师可优化笔画，但每层ID、交叉和终点不能随意改变：


设计时把C与D在 `(520,355)` 至 `(700,450)` 做**可观察的共线叠墨段**：深墨D局部压住赭红C，但留几段赭红边缘，放大和描图尺才能读出D在后。A与B在营地附近另有一次笔迹相压。不要只凭四种颜色排序；灰铅擦淡、不同笔压、折痕上的旧线和背注构成互证。路径描绘的是**修改版本**，不能被动画当成“队伍走过的轨迹”。

### 纸背精确文本与排版

背面不放另一幅路线图，只放四条更新语及底部空栏。每行左端以一小段与正面墨色相同的**非编号**短划关联，不写A/B/C/D给玩家。示意：

| 起点 `(x,y)` | 完整文本 | 版面要求 |
| --- | --- | --- |
| `(210,280)` | `沟口落石，绕行。` | 第一笔较淡；关键字不得被折痕盖住。 |
| `(210,405)` | `北滩水涨，船未至。` | “未至”清晰，不能少这一字。 |
| `(210,530)` | `下滩水急，未报可渡。` | 与“不可渡”严格区分。 |
| `(210,655)` | `探路未回，暂不放行。等信再定。` | 最后一行最深，但不做绝对命令式官方公文。 |
| `(1160,790)` | `江北——` | 留白处不做刮刮乐、藏字或解锁后显字。 |

所有简体字与标点人工复核；如透明PNG书法无法在200%放大时清晰，则改矢量/网页字体，不能为了“旧”牺牲辨认。不要伪造可供辨认的真实军令日期、单位或签名。

## 4. 触发区与动作，不预先给答案

命中区绑定局部痕迹而非整张纸，位置可用透明 SVG `<path>`／`<rect>`；CSS默认 `cursor: default`，靠近时变为轻微纸纤维高亮与 `cursor: pointer`。**命中区本身不绘制数字、红圈、透视光柱**。玩家也可用键盘通过“观察纸面”列表逐项聚焦，避免纯靠像素寻宝；列表只写位置“折角／北滩旁注／下滩线尾／交叠处”，不揭示结论。

| 内部ID | 面／命中区起稿 | 动作和触发 | 对应卡 |
| --- | --- | --- | --- |
| `map-near-route` | 正面 `(270,310,420,420)`，以路径附近胶囊碰撞区为准 | 展纸后侧光或放大可看覆盖；点击较淡起线/折角 | 《近路被改》 |
| `map-north-bank` | 正面 `(1020,235,225,180)`＋背面第二行 | 沿B移至北滩，点击旁注；翻背可复核 | 《渡口没有船》 |
| `map-lower-bank` | 正面 `(980,550,235,190)`＋背面第三行 | 顺C找断尾，点击字迹；可先于北滩发现 | 《另一处也没有答案》 |
| `map-crossing` | 正面 `(590,350,350,250)`＋背面末行 | 用描图尺放大交叠；手动核对末行，点击D末端 | 《在高处等信》 |

四张卡允许**发现次序自由**，但手账按照证据先后排序；“在高处等信”可以先触到，只先显示纸面观察，不直接总结前三次原因。待另外三张读完，再补上完整叙事卡。玩家不需要亲手拖着线走完全程才触发；在键盘、触控板和125%缩放下都能完成。所有工具可重复用，不存在选错后锁死。

工具栏只保留：`展开／翻面`、`侧光`、`放大`、`描图比较`、`重看故事`。描图比较是可拖动的半透明纸片，按住后出现A—D线的局部对照，**不自动标“最后路线”**。放大以鼠标位置为中心且有限位；重置视角可一键回完整纸面。纸张翻面保留缩放中心但不使热点漂移。

## 5. 页面与存档接线表（实施目标）

当前 `map` 已使用专属调查台及独立史实展柜，并复用账号／云存档 API 与章节解锁。以下表格同时记录已实现的流程和仍待PC试玩的细节；完成状态以账号服务端为准，本机暂存未同步时仍明确提示。

| 页面 | 未来行为 | 最小存档内容 |
| --- | --- | --- |
| `/archive` | 名单归档后解锁“行军图”；未解锁只显示封存，不剧透“等信” | 继续沿用对象解锁状态。 |
| `/object/map` | 四线调查、四张隐藏故事卡、展签核对、保存虚构故事 | 四个线索ID进入 `foundClueIds`；`completedInteractions` 记录展开、翻背、正确展签与故事保存。侧光、描图尺位置不入云端。 |
| `/history/map` | 从独立“翻阅真实档案”按钮进入，四站阅读并可返回 | `historyRevealed`＋`map-history-01..04`＋`historyRead`；后端已测试四条线索与阶段记录的保存、退出后恢复。 |
| `/history`／路线索引 | 只公开已完成章的真实史实；地图历史标签应从现有“遵义与赤水”扩充为“遵义—赤水—金沙江”或同等准确表达 | 按现有归档状态，不将游戏四条线叠到真实地图。 |
| 返回档案室 | 史实读完、建档成功才顺序解锁电池盒；重访不重复加进度 | 服务端确认 `archived` 后刷新仍一致。 |

旧通用 `map` 记录若使用已废弃线索ID，或旧核验状态缺少新版故事标志，载入时只重开行军图一章；账号、名单和其他章节记录保留。此迁移需在正式发布前对既有玩家明确告知并提供备份方案。网络失败时保持“本机待同步”状态，不显示“已云端归档”。

## 6. 专属素材与生图提示词

不生成“真实1935军用地图”“四渡赤水复原地图”或带可读汉字的图片；那会把史料边界和几何精度同时做坏。AI只生成**不承载史实与答案**的位图底材，其余用SVG和人工排字。

1. `map_paper_blank.png`，横向8:5，建议3200×2000、RGBA透明。完整提示词：

   > 为一款PC端历史主题叙事游戏生成一张**原创、完全虚构的旧纸底材**。只有一张完整、横向、平整的20世纪上半叶风格行路草图用纸，垂直俯拍、无镜头透视，纸占画布约88%×84%，四周透明。纸色暖米灰，细纤维、柔和折痕、极少量手持磨损；中央绝大部分区域亮度均匀，以便后续由程序绘制虚构地形和四层路线。纸边自然但不破碎，画面没有任何可读字、墨线、河流、等高线、符号、印章、纹章、真实地理名称或水印。不是馆藏原件的复刻，也不要参照任何真实红军地图。高分辨率、清晰、低噪点。

2. `map_paper_back_blank.png`，**必须以已选正面为空间参考**，同尺寸和同纸轮廓。提示词：

   > 根据上传的原创旧纸正面底材，生成**同一张纸的空白背面**。垂直俯拍，外轮廓、主要折痕、四角磨损和光线方向与参考图对位；只改变背面纤维和极浅的透墨阴影。中部保留四行整洁的书写空区，右下保留一处空栏。不要生成文字、线条、地图、印章、军令或人物。透明背景，尺寸与正面一致。

3. 可选 `map_raking_fiber.png`，2:1透明微观纸纤维。提示词：

   > 仅生成旧纸表面低角度侧光照出的细纤维与压痕微纹理，透明背景，边缘自然淡出，低对比、无外轮廓。禁止任何字、路线、地图、污泥、手、光斑和箭头。此层只作视觉质感，不能成为线索本体。

统一负面约束：无汉字/数字/乱码/伪书法、无真实地图或战争徽记、无水印logo、无黑底、无斜视透视、无烧焦血迹、无夸张破洞和大面积污渍。生成图若带伪字或无法抠透明，淘汰而不是在上面继续修。

## 7. 上线验收

- 断网及后端重连、刷新与不同PC缩放下，四卡和已读史实不丢；未同步时不谎称保存成功。
- 玩家不用看制作说明，能解释每一条线**因何改变**，并把“最后停在高地”与“最终过河”分开。
- 交叠在200%放大下清楚，侧光不盖字；右侧手账不会出现12px以下的关键文案，卡片正文段落不超屏。
- 所有信息都可用鼠标或键盘获取；减少动态效果时不影响折角、交叠和最终判断。
- `/object/map` 永远有“原创叙事道具”角标；`/history/map` 开篇清楚告知转入真实史实，正式包不含未获授权的30张研究图。
