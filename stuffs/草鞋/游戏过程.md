# 第四件「草鞋」史实资料包
## ——绣球草鞋：春秀说"我会等"，谢志坚说"我会回来"；17年后回来，草鞋如故，故人不在

> 用途：为数字叙事游戏《第四件：草鞋——旧补料的来处》提供史实原型与可引用材料。
> 核心文物：**绣球草鞋**（长26厘米、宽8.5厘米，黄麻精编，鞋尖各绑一枚红心绣球），现藏于都中央红军长征出发纪念馆（2021年入藏/借展中国共产党历史展览馆）。
> 人物主线：红军战士**谢志坚**（于都县岭背镇燕溪村人）与恋人**春秀**。
> 叙事落点：草鞋上的"旧补料"（布条/编结修补）与"红心绣球"，是**等待与回响**——春秀等了一辈子，谢志坚把一场没办成的婚礼用绣球补给了她。
> 资料整理日期：2026年10月18日。所有引文附来源，口径差异并列注明。

## 一、为什么这个故事与游戏设计严丝合缝

游戏中的"草鞋"是一双有使用痕迹的草鞋：鞋底有**带状旧补料**压住断开的编结，鞋侧小票记"任务：转三，材料：备用背带，数量：一段，用途：补履二只"，小票背面是"留一组照应，候后随二人同行"——玩家要弄清"补料的来处"，即第三件电池盒领出的那一段备用背带，最终落在这双草鞋上。史实原型"绣球草鞋"恰好是一双真实存在、被反复修补与珍视、承载等待与承诺的草鞋。

## 二、故事全貌（按时间线）

### 1. 少年谢志坚（1928—1933年）

谢志坚，江西省于都县岭背镇燕溪村人，贫苦农民家庭出身，从小放牛。1928年，14岁的他看到路过村里的红军为百姓出头，心生向往，跟着参加了红军。最初在红一军团三军八师特务连，后调到师部任号兵、通讯员、警卫员。在中央苏区征战的六年里，参加过一至五次反"围剿"战斗。"参加红军前，谢志坚曾为红军当向导、送情报"，他机智有胆略，深得红军官兵喜爱，也赢得了同村姑娘春秀的爱慕。（来源：凤凰网2024；中国军网2026）

### 2. 于都河畔的送别（1934年10月）

1934年10月，86000多名中央红军将士在于都集结完毕，即将战略转移。出发前夜（一说是重阳节前），春秀连夜编织草鞋相赠。谢志坚擦去春秀脸上的泪水："别哭，红军会回来的，我也会回来的，你安心地等待红军的好消息吧！"春秀使劲点头："我相信，我会等。"

出发那天的于都河畔挤满送行乡亲。春秀一身红衣，提着装满茶叶蛋、炒花生（另有豆包、米果、盐豆子之说）的竹篮赶到渡口，把吃食一把一把往谢志坚和战友们的包里塞，高声说："首长，红军兄弟，今天是我和志坚的好日子""志坚，来，拿鞋子、吃果子，吃了穿了打胜仗，不忘回家乡。"所有人都愣住了，战士们齐刷刷抬起右臂，立正敬礼，向春秀和乡亲们致敬。（来源：中国军网2026；于都县政府2024）

### 3. 只穿过两次的草鞋（1935年）

在炮火纷飞的长征路上，谢志坚把这双草鞋视若珍宝，**只穿过两次**：

- **第一次：1935年5月北渡金沙江**。老百姓用民船帮助红军渡江，这让他想起于都河畔的离别、家乡的亲人和春秀，小心翼翼地穿上草鞋，心里乐滋滋地过了江。
- **第二次：强渡大渡河**。面对敌人的枪林弹雨，谢志坚和战友们早已将生死置之度外。他暗想：若此时不穿，或许就再无机会。"死也不能和春秀的草鞋分开"。

血战湘江、四渡赤水、鏖战娄山关……一个接一个硬仗，这双草鞋陪他一次次闯了过来。（来源：中国军网2026；于都县政府2024；南方+2016）

谢志坚的女儿谢婷讲述："大渡河和金沙江都是恶战，很多战友就牺牲了，他这个时候就会想到万一我牺牲了，还是把草鞋穿在脚上。因为春秀阿姨在于都也是红军，她只是没有跟随部队去长征。看到这双草鞋，我爸爸就想到这就是春秀在我身边，等于是一起参加革命，一起在战斗。"（来源：央视2026）

### 4. 滞留甘肃，音讯断绝（1935年秋）

部队进入甘肃境内后，谢志坚突发重病（一说疟疾）无法行军，被组织安排在当地养病。这一留，山高水长、此去经年，他与部队、与春秀彻底失去联系。此后十几年，他多少次梦回于都河。有后人回忆，他在异乡以做工谋生，仍坚持讲红军的故事、宣传共产党的政策。（来源：凤凰网2024；中国军网2026；今日头条《51年，老红军谢志坚…》，自媒体细节仅参考）

### 5. 17年后的重逢（1951年）

新中国成立后，当于都河畔的乡亲们都以为他牺牲在长征路上的时候，他回来了。**1951年**，谢志坚回到于都寻找春秀，却得知：红军长征后，春秀因积极与反动派做斗争，惨遭敌人杀害，早已不在人世。

"那个说了'我会等'的姑娘却早已牺牲""十几年过去，草鞋如故，故人却阴阳两隔"。谢志坚带着草鞋来到春秀墓前，放声痛哭。（来源：央视2026；于都县政府2024；凤凰网2024）

### 6. 补上的婚礼：鞋尖上的红绣球（上世纪80年代）

上世纪80年代初，中央红军长征出发纪念馆馆长张德美（曾任于都县委秘书）在走访革命老同志时听说了这双草鞋的故事，三番五次登门，恳请谢志坚把它捐给纪念馆。老人答应了，但在捐出之前，他做了一件让所有人动容的事——**在草鞋的鞋尖上亲手绑上一对红心绣球**。

红绣球是当年赣南姑娘出嫁时才会用的东西。那场1934年10月没能办成的婚礼，他用这种方式，在半个世纪之后补给了她。"这双鞋从此不只是一件革命文物，是一场迟到了五十年的婚礼，是一句'我会等'的回音。"（来源：中国军网2026；今日头条/北京晚报2016）

此后，纪念馆成了谢志坚余生的念想。他常常一个人站在展柜前看很久；即便病重期间，也让儿孙搀扶着，**三次到纪念馆看这双草鞋**。（来源：南方+2016；凤凰网2024）

### 7. 后来的事

- 2021年，这双绣球草鞋由中国共产党历史展览馆收藏（于都县政府称"借至北京的中国共产党历史展览馆"），向全国青年讲述长征与红军的故事。（来源：央视2026；于都县政府2024）
- 2019年5月20日，习近平总书记在江西于都参观中央红军长征出发纪念馆时，在绣球草鞋展柜前**久久驻足凝视**，并仔细询问新中国成立后老红军谢志坚的待遇。（来源：于都县政府2024）
- 谢志坚的四女儿谢建华说："现在，父亲不在了，我们每年都要打几双草鞋，既是纪念，也是传承。"（来源：新华网/今日头条2019）
- 2026年10月，有报道称根据这段真实事迹改编的电影《一双绣球草鞋》全国公映（长征胜利90周年献礼片；自媒体传播，**官方确认待核**，作彩蛋参考）。（来源：今日头条2026，待核）

## 三、文物档案

| 项目 | 内容 |
|---|---|
| 名称 | **绣球草鞋**（"老红军谢志坚穿过的绣球草鞋"） |
| 规格 | 长26.0厘米、宽8.5厘米 |
| 材质 | 黄麻手工精编（于都当地"最柔软、最坚韧"的植物纤维），鞋尖各绑一枚红心绣球 |
| 等级 | 展陈说明牌标注**国家一级文物**（凤凰网2024图版）；央视称"非常罕见的红军长征时使用的实物" |
| 收藏 | 于都中央红军长征出发纪念馆；2021年入藏/借展北京中国共产党历史展览馆 |
| 特征 | 鞋面有使用磨损痕迹；编结细密；与普通稻草草鞋不同，用料是柔韧的黄麻 |
| 关键物证细节 | 红心绣球为谢志坚上世纪80年代捐赠前亲手绑上——既是赣南出嫁装饰，也是他对春秀的纪念 |
| 相关展陈 | 于都纪念馆同柜陈列"红军用过的藤篮子"；馆内另有80双草鞋拼成的中国地图（草鞋墙） |

**外观描写（可直接用作游戏道具文字）**：
> "黄麻编的，针脚细密，做工精致得不像一件行军装备。更特别的是，鞋尖上绑着一对鲜红的绣球。"（今日头条/博物馆讲解语）
> "和其他红军穿戴用过的实物不同，这双草鞋几乎还是全新的，编制鞋子的材料也不是一般的草鞋用料，而是柔软舒适的黄麻，每只鞋的鞋面上还顶着一只漂亮的绣球。"（中新网2016）

## 五、真实性证据链

### 1. 文物
- 绣球草鞋有明确规格（26.0×8.5厘米）、材质（黄麻）、馆藏地（于都中央红军长征出发纪念馆；党史展览馆），多方权威来源（央视、中国军网、于都县政府、中新网）互相印证。
- 展陈说明牌标注"国家一级文物"（凤凰网2024实拍图OCR可见）。
- 鞋尖红绣球系谢志坚捐赠前亲手所绑，为当事人直系亲属（谢婷、谢建华）与馆长后人（张小平）多方口述确认。

### 2. 人物与家属
- 谢志坚确有其人：于都岭背镇燕溪村人；燕溪村党支部书记谢建华（凤凰网2024）指证其参军前经历。
- 女儿谢婷（央视2026采访）、四女儿谢建华（新华网2019）可证；后人"每年打几双草鞋"延续传统。
- 纪念馆馆长张德美动员捐献、其子张小平（副馆长）亲述（北京晚报2016）。

### 3. 文献互证
- "只穿过两次（金沙江、大渡河）"在央视、中国军网、于都县政府、凤凰网、南方+五处独立来源完全一致。
- 1951年回于都、春秀牺牲：央视、凤凰网、南方+、今日头条一致。
- 红心绣球绑于捐赠前：中国军网、北京晚报、今日头条一致。
- 2019年5月20日习近平总书记驻足凝视：于都县政府官方记载。

### 4. 已知存疑/待核事项
- 谢志坚参军年龄与年份：凤凰网作"1928年，14岁"；央视海报作"1934年20岁"——两说在年代推算上可自洽（1914年生：1928年14岁、1934年20岁），但出生年份未见官方明文，标注并存。
- 春秀送鞋数量：多数来源为一双；有"四双"（共产党员网视频）与"六双"（自媒体）异说，以一双为准。
- 春秀身份：多数来源为"恋人/未婚妻"；今日头条自媒体称"岭背乡草鞋队队长"，官方来源未见，待核。
- 苏区赶制草鞋总数：央视"20多万双"、新华社稿"20万双"、北京晚报/张小平"10万多双"（于都红军渡河前夕）——口径差异并存。
- 电影《一双绣球草鞋》2026年公映：自媒体传播，官方确认待核。
- 2021年绣球草鞋是"入藏"还是"借展"党史展览馆：央视作"收藏"，于都县政府作"借至"，并存。

## 八、配套素材（用于游戏器物与制度背景）

### 1. 草鞋是登记在册的战略物资
- 苏区妇女支前：出发前夜以继日赶制草鞋（央视"20多万双"、新华社"20万双"、北京晚报"10万多双"三口径并存）；红八军团驻地旧址统计展板"1934年5-10月草鞋8400双、菜干150担（不完全统计）"——草鞋有组织、有登记、有统计。
- 《红星报》刊《怎样解决草鞋问题》；1935年1月朱德、周恩来电示红1军团"每人须准备三双"草鞋（行军图资料包第七节）。
- 结论：游戏中"草鞋领用联（任务、材料、数量、用途）"的登记形态，在苏区支前统计与部队给养制度中有真实对应。

### 2. 补料与循环
- 草鞋磨穿即换、破了用布条麻绳修补；绑腿布、破衣撕条补鞋是长征真实生活（电池盒资料包第八节）。
- "打双草鞋送给郎，南征北战打胜仗，穿上草鞋跟党走，刀山火海不回头"——红色歌谣可作游戏文案（凤凰网2024）。
- 结论：一段备用背带（电池盒领出）→补履二只（草鞋），完全符合长征物资循环逻辑。

### 3. "候"的三重真实对应
- 春秀："我相信，我会等"（等来的是牺牲）；
- 谢志坚："红军会回来的，我也会回来的"（17年后回来，用绣球补上婚礼）；
- 薛岳追到皎平渡，只捡到红军一只草鞋（行军图资料包）——"遗落"与"候同行"。
- 结论：设计小票背面"留一组照应，候后随二人同行"的"候"字，在史实中有最深沉的情感底色。

### 4. 草鞋墙
于都中央红军长征出发纪念馆内80双草鞋拼成的中国地图——"长征出发的地方，草鞋铺成回家的路"（行军图资料包第七节；可作关卡背景）。

## 九、给游戏改编的具体建议（沿用"不替玩家下结论"原则）

1. **补料的呈现**：设计中的"带状旧补料"用布条材质（真实草鞋修补常用）；可让玩家在草鞋编结中看到两种材质（草/麻编结 + 布条补料），对应"备用背带（布）补草鞋"。
2. **红心绣球**：作为"候"的视觉符号——绣球是赣南出嫁装饰，谢志坚用它补了一场50年前的婚礼；玩家最后发现绣球时，可触发"候"的情感收束。
3. **小票核对**：草鞋领用联（转三、备用背带、一段、补履二只）与电池盒领出联逐项核对后闭合——材料去向链完整（盒内记录→领出→补鞋）。
4. **"候后随二人同行"的留白**：真实里春秀与谢志坚的"同行之约"以牺牲与17年错位告终；游戏不必补全"后随二人"的结局，让"候"停在记录里。
5. **情感文案素材（原文可用）**："我相信，我会等""吃了穿了打胜仗，不忘回家乡""今天是我和志坚的好日子""别哭，红军会回来的，我也会回来的""死也不能和春秀的草鞋分开""这双草鞋就是我爸爸想到的春秀在我身边"。
6. **彩蛋（可选）**：2019年5月20日习近平总书记于都驻足凝视绣球草鞋、询问老红军待遇；谢建华"每年打几双草鞋"的传承；"打双草鞋送给郎"歌谣。
7. **数字口径**：草鞋规格26.0×8.5厘米直接用；苏区草鞋总数用"20余万双（央视）/20万双（新华社）"，不叠加北京晚报"10万多双"于同一句，避免混淆。
8. **可实地采风**：于都中央红军长征出发纪念馆（草鞋墙、绣球草鞋展柜）、于都岭背镇燕溪村、于都纪念园、长征国家文化公园核心区（4.5公里红军长征步道）。

## 十、口径差异（资料中并列保留，游戏中不做唯一化处理）

1. 谢志坚参军：凤凰网"1928年，14岁"；央视海报"1934年20岁"——年代推算自洽（约1914年生），出生年份无官方明文。
2. 春秀送鞋数量：一双（主流）/四双（共产党员网）/六双（自媒体）。
3. 春秀身份：恋人/未婚妻（主流）；"岭背乡草鞋队队长"（自媒体，待核）。
4. 苏区草鞋总数：20多万双（央视）/20万双（新华社）/10万多双（北京晚报·张小平）。
5. 草鞋"入藏"还是"借展"党史展览馆：央视"收藏"、于都县政府"借至"。
6. 谢志坚滞留甘肃病因："突发重病"（主流）；"疟疾"（自媒体细节）。
7. 绣球颜色：多数来源"红心绣球"；凤凰网图片说明作"粉色红心绣球"；央视图片可见粉白渐变绒球——材质为红（粉）色线球，描写不冲突。
