# 第四章《不成双》

本目录是草鞋章的制作入口。玩家先检查两只原创虚构的草鞋，保存一条有边界的展签；再主动打开独立的真实史实展柜。它既不是第三章电池盒的续篇，也不是第五章饭碗的身份线索。

## 文件顺序

1. [情节与史实撰写方案](草鞋章节-情节与史实撰写方案.md)：故事、四段线索、选项、解锁与历史四站的定稿口径。
2. [美术资产清单与逐张制作提示词](草鞋章节-美术资产清单与逐张制作提示词.md)：分层母版、SVG 字图及生图验收。
3. [前端制作坐标与 SVG 方案](草鞋前端制作坐标与SVG方案.md)：桌面端场景、点击热区、各状态与页面跳转。
4. [史实展柜与核权清单](草鞋章节-史实展柜与核权清单.md)：材料出处、不同说法、图片权利与上线检查。
5. `美术母版/`：原创游戏图；`史实视觉/`：原创后制史实示意图。

`游戏过程.md` 是前期研究底稿，**不再是制作口径**。其中“电池盒背带接到草鞋”“转三后随二人”“真实绣球草鞋反复修补”等设想已废弃，不能进入玩家可见页面。

## 章节边界

- 虚构：不成双的两只旧鞋、外绳、无名档案登记与所有点击所得故事片段。
- 真实：长征时期草鞋的供给，以及谢志坚、春秀和绣球草鞋的公开报道。
- 两者只在“人如何带着鞋走、又如何把记忆留下”的主题上相遇；不指认游戏草鞋为馆藏原件。
- 研究图片 `史实材料/images/` 仅供内部核对。未经许可不直接复制到产品。
